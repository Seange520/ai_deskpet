本地安装密钥使用 32 字节 Web Crypto 随机数，随机 UUIDv4 经 HMAC-SHA256 派生六位安全 base32 编号。编号生成后冻结。不提供服务器唯一性声明；同机重新生成也不承诺全局无冲突。无 Web Crypto 时拒绝生成。

只写 identity.v1 与 install.v1。旧进度与 ui:layout:v1 仅通过受控键表读取，坏 JSON 视作缺失。导出为 Blob 下载，包含档案白名单与各键解析后的原始 payload；不含安装密钥和出生年份。导出后记录时间，删除仅移除上述两个键。
