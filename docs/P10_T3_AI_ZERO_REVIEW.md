## 运行与边界

开发服务器：`npm.cmd run dev -- --port 15262 --strictPort`。访问 `/?world=p9&quality=3&aiTest=1`；右上「零 · 档案」。生产构建与 Tier0/1/2 不加载 AI；`ai=0` 优先关闭。生产开关通过 `import.meta.env.DEV` 静态消除。AI 所有应答标注内部 `source: 'local-mock'`，UI 设置明确本地模板预览、零成本，无真实模型或联网能力。

数据流：清洗（NFKC、去控制/零宽字符、500 Unicode 字符）→ 四类输入守门 → 教学前置/章节预过滤 → 关键词评分、模板槽位 → 禁止词/越级词/引用再校验 → 300–600ms → 可关闭打字机。React 文本渲染，不解释或执行输入。零负责陪伴短句，校验体随测量/错误等行为切换；回答不含直接修复答案，不产生游戏操作。

RAG 读取真实 knowledge-graph 和 lesson JSON 的 KP 元信息，不索引题目答案、未公开剧情或 CANON 的 OPEN 设定。`CANON_RULES` 为只读文档规则的人工摘录，来源指向外置交接台账 §3/6/8；不将台账真相整份打包。已有教学档没有章节揭示字段，适配器默认 `maxSeenSpoiler: 0`；纯函数支持显式 0–7，禁止由询问文本提升。未命中统一使用「档案缺失」与观察引导。

诊断只读订阅街区 `reading` 引用变化；同测点/同模式连续三次触发。捕获玩家实际确认按钮后读取证据不足消息，第二次失败触发。另支持对话自述测量/错误；每类诊断键只记录一次 `aideDiagnosis`，只给一条比较线索。没有修改 dispatch、tick、教学完成或奖励逻辑。

## 记忆与限额

四层：最近核对 12 轮、事件摘要 20 条、教学语义实时只读、探索关系/选择实时只读；另有最多 3 条偏好。时间戳严格校验，180 天到期裁剪。摘要是固定事件概述，最近记录也会截短；不声称具有模型长期理解能力。选择只来自探索 store，不复制进 AI JSON。

默认不写 localStorage。用户在设置中单独授权后，仅写 `sparkmate.ai.memory.v1`；授权不反写身份档。撤回授权删除持久记忆；清空同步删除独立键、会话对话与诊断，取消待响应定时器，保留本次用量以免清空绕过限额。配额元信息（仅日期/轮数/字符数）另在同名 sessionStorage 键维持刷新计数，不包含聊天或偏好。跨日重置 60 轮，本地 mock 费用恒为零。

本地限额属于演示护栏；清除浏览器存储或新开隔离会话可重置，不能替代将来服务端限流。未授权时不提供跨浏览器会话记忆。生产路径连模块都不加载，因此不产生 AI 存储读取或写入。
