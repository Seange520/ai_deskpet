### ✨ UI 视觉革命 (UI & Visuals)

- **feat(ui): NumberTicker 数字滚动微交互**：顶栏累计 XP 与路线任务数量首次进入视口时递增显示；复用 Framer Motion，并提供弱动画静态降级。对应提交：`ac53a14`。
- **feat(ui): SpotlightCard 边缘跟随光效**：Dashboard 三张关卡卡片采用 1px 指针跟随边缘光，关闭原卡片光源，保留倾斜、磁吸与分层视差。对应提交：`ac53a14`。
- **feat(ui): ShineBorder 当前关卡流光聚焦**：为当前路线首个未完成步骤增加缓慢流光，三步全部完成后不再显示；弱动画下保留极淡静态边框光。对应提交：`030b44d`。

### 📊 数据看板重构 (Dashboard)

- **feat(dashboard): 成长总览、XP 进度环及里程碑**：新增独立成长总览，展示累计 XP、等级、升级差额与 500/1000/1500/2000 XP 刻度；达到 2200 XP 时显示“课程 XP 已集齐”。
- **feat(dashboard): 路线任务矩阵与成就增强**：四条硬件路线按物料、接线、参数实验和代码挑战分别展示进度，标明当前路线及锁定状态；保留四枚原有徽章，新增故障修复总数与下一枚勋章提示。

本模块对应提交：`89642cd`。展示数据只读派生，不修改主学习 Store、XP、解锁或存档迁移规则；保留原三个核心 article 与操作入口。

### 🔌 硬件体验升级 (Hardware Mock)

- **feat(hardware): 纯前端浏览器演示通道 (Browser Demo Provider)**：无需 Node、USB 或后端即可开启内存字节流，经共享连接器和原 JSON 解码器接收遥测；模拟遮光/恢复光照通过真实读取链路驱动 Companion 暗光休眠/恢复。对应提交：`4a6ec9e`。
- **feat(hardware): 实时 SVG 光感波形与事件日志**：最多保留 60 个光照样本与 40 行分类日志，明确区分模拟器事件、已解析遥测和异常提示；数据仅存在于演示会话，不写全局 Store 或 localStorage。对应提交：`95d952e`。
- **feat(hardware): 异常场景控制（暂停/拔线/脏数据）**：新增默认折叠的演示场景；暂停保留连接和最后读数，模拟拔线复用共享清理并提供重连，非法数据由原解码器拒绝后随下一条合法数据恢复。对应提交：`339ce41`。

浏览器演示、真实 Web Serial 与原 Node 虚拟桥接互斥；模拟来源始终明确标注。不新增依赖或后端，不发送真实设备控制命令，不自动烧录固件。
