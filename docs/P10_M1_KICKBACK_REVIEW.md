## 模型参数与可复核含义

| 参数 | 本轮取值 / 含义 |
| --- | --- |
| 供电 / 控制器 | 24 V 工作支路 / U1 标称 5 V；0 V 工作回流不等于 PE |
| L / R / 时间常数 | 0.12 H / 24 Ω / 5 ms；`I(t)=Vs/R·(1-exp(-tR/L))`，闭合 0.6 s 接近 1 A |
| 储能 | `E=½LI²`，约 0.06 J/次；无随机数 |
| 未钳位分断 | 约定电流变化时间 0.5 ms；`Vpk=24+LI/Δt=264 V`，属于未钳位应力估计，非雪崩后实际节点波形 |
| 耐受与耦合 | 开关窗口 60 V；U1 窗口 5.8 V；显式教学耦合系数 0.006，`U1pk=5+max(0,Vpk-24)·0.006`，未修复约 6.44 V |
| 续流二极管 | 阴极接 +24 V 侧，正向压降 0.7 V，开关峰值约 24.7 V；放电电流按带正向压降的 RL 衰减，截断于零 |
| RC 吸收 | 串联 R=10 Ω、C=470 µF；保守上界 `24+I·(sqrt(L/C)+R)` 约 49.98 V，两条耐受窗口均不越界 |
| 超阈累积保护 | 每次失败累加 `E·(1-60/Vpk)`；阈值 0.12 J，第三次失败进入保护；需隔离、放电后人工复位 |
| 可观察时间 | 周期 1.2 s、0.6 s 时开断；屏幕/独立支路街灯复位包络展宽 0.5 s；不是实际继电器响应速度 |
| 交流档 | U1 的失效复位包络按 `5·sqrt(d·(1-d))`、`d=0.5/1.2` 求交流耦合 RMS，约 2.47 V；健康基线 0.03 V。其它端按约定脉冲包络求值。读数为最近一次事件的保持值 |
| 放电与专注 | 隔离后余压按 0.12 s 时间常数衰减，低于 1.5 V 才开放离线操作；鹰眼 -5/s、测量 -6、关闭恢复 +10/s；误档罚记最多 12，免费更换仪表保险，无 XP/物资负债 |

本轮固定 D1 缺失的初始场景，等效开路失效同样没有钳位路径；未引入随机出题。续流与 RC 的能量记入吸收量，未钳位能量记入应力；参数用于因果教学，不是 SPICE、真实器件选型或认证。电压档明确标记峰值保持，交流档明确标记约定包络 RMS，不假装通用手持万用表能解析 0.5 ms 尖峰。

依据：TI [Inductive-load switching](https://www.ti.com/document-viewer/lit/html/SLVAF04)、[Solenoid driving](https://www.ti.com/document-viewer/lit/html/snvaa45)，OMRON [Relay countermeasure](https://www.ia.omron.com/support/faq/answer/36/faq02804/index.html)、[Coil surge absorption](https://www.ia.omron.com/support/faq/answer/18/faq02129/)。这些资料支持储能、续流与吸收的基本因果；上述耦合系数、窗口、展宽时间和 RMS 观察包络由本切片明确约定，不归因于资料中的实测。

## 操作闭环与教学检测

1. `?quality=3&world=p9` → 开始自由探索，沿东侧原连桥进入冷库柜体附近。首次入场自动打开微课；真实累计 30 秒、单选答对才写入 `lesson:back-emf`，期间没有仪表可操作。三条内容只讲现象/条件/原理，不指认 D1。
2. 从三个预设假设中记录 2–3 条。系统不评分，存档保留所选条目。
3. 观察一次 K1 分断，用电压档 600 V 捕获 K1 峰值、交流档 20 V 比较 U1 包络、电流档 10 A 接预置 M2 串联口。20 V/200 mV 等不足量程显示 OL，不给有效证据。电流误跨接或 200 mA 过量程熔断仪表保险，断电免费更换。
4. 断电并确认余压释放，通断档测 K1 工作回流、电阻档 2 kΩ 测 M2、二极管档测 D1 两个方向。带电/余压期间离线档与装配被联锁拦截；电容档和反向二极管读数单独记录，不能冒充正向二极管证据。
5. 假设 + 六类有效读数才允许诊断。选择续流二极管时错误极性被拦截；或选择串联 RC。断电修复后恢复供电，逐次执行 10 次开断，任何失败/断电都会终止并重置连续计数。
6. 首次十次全通过才触发“十次开关都响过了，灯一直亮着，冷柜也没再停。”，奖励 100 XP + 1 记忆棱镜；读到波纹的中途台词也随测量变化。NPC 只说可观察现象。

| 机制 | 可检测学习行为 |
| --- | --- |
| 微课 | 真实计时、提前提交禁用、错误答案不解锁、答对存档 |
| 假设 | 至少两条、去重、无评分、刷新保留 |
| 六透镜/量程 | 点实际空间测点、OL 不算证据、断电档联锁、表笔方向/电容分开 |
| 工程反应 | 无微课不触发；K1 分断与测得尖峰/复位对应；仪表错误接法触发另外两条保护 |
| 诊断/维修 | 六类证据门控；带电与反装拒绝；两种修复均经模型重新求峰值 |
| 验收/反馈 | 十次逐次阈值判定、中断归零、现象台词、一次性奖励 |

没有独立刷伤害、战利品或无教学进度的爽点循环；电弧与灯光是上述分断/保护状态的反馈。按可操作机制计，未添加纯爽点机制（0/6）；这属于实现核对，不能替代用户体验研究中的 20% 指标测量。
