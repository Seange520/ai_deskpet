# SparkMate v0.9.1-beta 发布说明

- 发布日期：2026-11-04
- 发布类型：测试版（Beta）
- Git 标签：`v0.9.1-beta`（带注释）
- 变更基线：`a5a77e8`（v0.9.0-beta 发布说明提交）
- 封板范围：本轮已审核的开发者入口、硬件面板 UX 与补验文档。

## ✨ 硬件面板 UX 净化

- 普通视图仅保留真实 ESP32 与紧随其后的浏览器光感演示；不再显示 Node 桥接入口、8765 端口或 Node 专属报错。
- 浏览器演示保持无需硬件、无需 Node 的完整光感联动、SVG 波形、事件日志与可控异常体验。
- 保留真实 Web Serial 的能力检测、授权反馈及错误提示，不掩盖真实设备故障。

## 🛠️ 开发者调试入口

- 硬件面板内聚焦控件后按 `Ctrl+Shift+D`，或连续点击“连接真实 ESP32”标题五次，显示独立“开发者调试”面板。标题相邻点击间隔超过 1.5 秒即重新计数。
- Node 虚拟光感端口、连接操作、状态与错误提示统一收纳至 `DevToolsPanel`。
- 入口状态仅驻留组件内存；刷新或离开工坊后恢复隐藏，不写入 localStorage。
- 关闭开发者面板时，若当前使用 Node 桥接则走共享断开流程；不会断开真实 USB 或浏览器演示。
- 此入口用于防误操作，不构成身份认证或安全权限边界。预留注释不代表启用跳过学习任务、真实烧录等功能。

## 架构与兼容性

- 不新增 npm 依赖或后端，不修改主学习 Store、串口解码器、现有连接器及连接互斥规则。
- 补验脚本通过与用户一致的标题手势解锁；保留原断言与测试覆盖。
- 不自动启动 Node 服务，不自动烧录或发送真实硬件控制命令。

## 已知开发环境提示

正常开发模式启用液态玻璃时，现有 `@khvicha/react-liquid-glass` 依赖会触发 React 的 `lighting-color` / `lightingColor` 属性告警。本轮未修改该依赖；新增补验明确计数并记录这条告警，其他控制台错误仍作为失败。生产预览不出现该告警；本轮未降低原 65 项 E2E 断言。
