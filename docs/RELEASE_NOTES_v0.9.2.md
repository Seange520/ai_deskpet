# SparkMate v0.9.2-beta · 暮色工坊 (The Twilight Workbench)

- 发布日期：2026-11-05
- 发布类型：测试版（Beta）
- Git 标签：`v0.9.2-beta`
- 上一版本：`v0.9.1-beta`，代码基线 `a9d0daca15ecbbdc86d8889d6d3a9091fa74306e`。
- 本版整合已审核的 PR-1 / PR-2 / PR-3；package.json 与锁文件根版本同步为 0.9.2-beta，依赖版本不变。

## 视觉环境：暮色中点亮一盏灯

- 全局改用暮紫面板、暖杏强调、暖白文字与低饱和生命绿，降低玻璃描边与外发光。
- 现有 3D 主光由 2.2 调整至 1.6；环境与主光色温转暖，日间补光柔紫、夜间低强度暖光。保留原灯光类型与生命周期。

## 空间纵深：微缩工作台

- Hero 使用纯 CSS 3D：1200px 透视、文字前层与 4 秒轻微悬浮，独立背景层裁切，保留原 Pet 与按钮语义。
- 桌宠下方加入柔和青绿光晕底座及弥散投影。
- Canvas2D 绘制 12 个暖色／柔紫光点，绘制限频；离屏、页面隐藏及业务弹窗时暂停，卸载清理 rAF 与观察器。

## 物理微交互：看板浮在桌面上

- 成长总览、路线任务矩阵、成就墙共享局部指针倾斜：角度限定在 ±3.5°，标题最多 translateZ(10px)，补偿透视放大。
- 矩阵保留 table 和 16 个只读单元格，以多层柔和阴影表现厚度；实际悬停使用 translateY(-2px) 模拟抬升，不新增点击行为。
- 已解锁徽章增加极淡径向光晕，未解锁徽章保留灰度并加入磨砂质感；原四枚徽章及解锁逻辑保留。

## 工程侧：守卫生态

- 零新增 npm 依赖、后端或重型动画库；保留现有 React、CSS、Canvas2D 和 Framer Motion。
- 小于 768px、粗指针、无悬停能力或 prefers-reduced-motion 下，新增空间效果降级为平面，关闭倾斜；Hero 不创建粒子 Canvas。
- IntersectionObserver 控制可见性；Dashboard 离屏移除指针监听。隐藏、弹窗和卸载均清理或暂停相关展示资源。
- 不改主学习 Store、XP、通关、串口解码或学习存档键；视觉交互不写 localStorage，原 2D 核心与单个 WebGL 场景保留。

## 验收记录

- 固化前执行 `npm run build:local` 和原 `npm run test:e2e`；核心回归保持 65 通过 / 0 失败 / 0 跳过。
- 本轮仅经用户批准更新一条旧背景色精确期望：rgb(15, 23, 42) → rgb(27, 22, 38)。用例数量、光效及原业务断言保留。
- 正常环境独立端口 5262，无 regression 参数：Hero 7 组、Dashboard 8 组专项补验通过；覆盖小屏／粗指针／减少动画、离屏暂停、监听释放、按钮导航，以及学习状态与 localStorage 不变。
- 页面隐藏分支使用 visibilitychange 事件模拟；浏览器补验不代表实体手机、实体 ESP32 或长期资源验收。
- 保留既有约 858 kB 的 3D 分包提示，未新增超过 500 kB 的 JS 分包。
