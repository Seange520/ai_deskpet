## 2. 四路线对比

| 维度     | 经典方块桌宠             | 迷你四足机器狗               | 履带 / 麦轮小车            | 球形自平衡机器人           |
| -------- | ------------------------ | ---------------------------- | -------------------------- | -------------------------- |
| 难度     | ⭐                       | ⭐⭐⭐                       | ⭐⭐                       | ⭐⭐⭐                     |
| 核心硬件 | ESP32-S3 · 屏幕 · 麦克风 | ESP32-S3 · 8×SG90 · 独立供电 | ESP32-S3 · L298N · 底盘    | ESP32-S3 · MPU6050 · 球壳  |
| 知识重点 | GPIO · 3.3V · 共地       | 舵机驱动 · 压降 · PWM        | H 桥 · 方向控制 · 电机供电 | I²C · 姿态估计 · 控制入门  |
| 代码实验 | 表情 / 眨眼 / 主题       | 关节角度                     | 正反转 / 调速              | 加速度 / 角速度 / 静态姿态 |
| 典型错误 | 电源接反                 | 舵机共地缺失、压降复位       | 带电换向、ENA 悬空         | 混淆 I²C 与 I²S、轴向误读  |
| 适合人群 | 零基础入门               | 想挑战机电结构               | 想做移动机器人             | 对控制算法感兴趣           |

> 四条路线共用同一套「三关 + 奖励 + 成就」框架，换路线不换学习方式，降低认知负担。

## 3. 与传统教学 / 同类产品的差异

| 对比项   | 传统实验课             | 通用仿真软件       | **SparkMate**                  |
| -------- | ---------------------- | ------------------ | ------------------------------ |
| 上手门槛 | 需先备齐硬件、装工具链 | 需学习专业软件操作 | 打开浏览器即学                 |
| 试错成本 | 接错可能烧板、烧器件   | 参数复杂、离教学远 | 虚拟烧板可恢复，零成本试错     |
| 学习动机 | 以完成任务为主         | 以仿真精度为主     | 桌宠 + 成就 + 音效的游戏化闭环 |
| 课程覆盖 | 单一实验               | 通用电路           | 四条硬件路线 + 分路线避坑笔记  |
| 可访问性 | 受实验室时间限制       | 依赖桌面端         | 多端适配、键盘可用、可投屏     |

## 4. 差异化亮点

1. **「多形态桌宠」叙事**：同一套桌宠情感系统映射到四条硬件路线，学习目标具象化为「让你的伙伴动起来」。
2. **状态驱动的一致性**：XP、徽章、排行榜、进度条同源，评审现场演示不会出现数据对不上。
3. **可测试的教学交互**：爆炸图、接线、音效都有自动化断言，不是「看起来能动」的演示页。
4. **数据驱动可扩展**：新增路线 = 新增一份配置 + 一份课程数据，核心组件零改动。
5. **诚实的产品边界**：明确标注教学原型、示例引脚与不可制造风险，适合作为大创项目的可信叙事。
