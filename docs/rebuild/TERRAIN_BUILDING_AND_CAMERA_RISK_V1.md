# 地形建造、布局视角与镜头风险 V1
《第七校验·流明域》· 2026-11-10 · 对应"4v1 要能改地形/造建筑，别做成第五人格；高机位布局；视角特效 bug"

## 0. 结论先说

- **4v1 里本来就有建造与地形改变**（校筑 + 登记/抹除），但之前写得不够"地形化"。这次把它抬成核心：**地形 = 电路拓扑**。
- **双方都能造**：校验员造「校筑」把地形"登记"出来；空页造「误读造物」把地形"读歪"。
- **高机位布局视角**：双方都有，但看到的信息不同（见 §3）。
- **镜头 bug 风险**：用"相机状态机 + 单后处理管线 + 分层特效预算"控制，不靠事后修（见 §4）。
- **其他玩法同步升级**：对称/抢修/卡组都加"地形层"（见 §5）。

## 1. 地形 = 电路拓扑（4v1 的差异化核心）

同一套 7 座校筑，**按电路连接方式**长出不同地形：

| 连接方式 | 地形结果 | 战术 |
|---|---|---|
| 串联（闸楼→闸楼→闸楼） | **长桥/长廊**：登记区连成一条可走的路 | 突围、转移、拉长追击线 |
| 并联（两路并到同一节点） | **双向门/双通道**：两条路都通，但共享一个开关 | 设伏、诱骗、假撤退 |
| 接地网络（地钉×N） | **安全地面**：站在上面不被抹除/不被读改 | 守校验位、救人 |
| 容井+闸楼 | **升降台/短时高台**：抬高视野、跨墙 | 抢高机位、躲追杀 |
| 阻墙+感桩 | **预警走廊**：墙减速、桩报警 | 封锁区、拖时间 |
| 变压台+熔断柱 | **爆裂地形**：自毁换大范围登记/塌方 | 终局翻盘、封路 |
| 三条串联+一个并联节点 | **环岛**：绕圈地形，追击变成绕桩 | 遛鬼、拉扯 |

**玩法一句话**：你不是在"放建筑"，你是在**用电路画地形**；画错=给对面送路。

## 2. 空页也造：误读造物（对称的"建造对抗"）

- 空页不是只会抹除，它能造 **5 种"误读造物"**：
  1. **假墙**：看起来是墙，实际能穿（或反之）；
  2. **回廊**：走进去回到入口（空间折叠）；
  3. **假校筑**：伪装成闸楼/地钉，触发即爆/断电；
  4. **读改桩**：范围内仪表读数错位；
  5. **空白渗口**：一小片"未登记"，人进去地形消失 2 秒。
- 校验员可以**验封/压印**拆穿（衡的技能就是干这个）。
- 于是 4v1 变成：**一边用电路拓扑造地形，一边用误读造物改规则**——不是"修机+跑"，是"造地图 vs 改地图"。

## 3. 高机位布局视角（双方都有，信息不同）

- **校验员·布局视角**：高机位俯视，看到登记区（实心）、未登记（留白）、校筑槽位、馈线、队友位置；可拖入校筑做"预演"（幽灵预览），松手回第三人称落地。
- **空页·抹除视角**：高机位俯视，看到"可抹/不可抹"热区、登记率、假造物伪装层；抹除前有前摇预览。
- 规则：布局视角**不暂停**（联机公平），只做半透明覆盖 + 降饱和；单人/剧情可暂停。
- 移动端：双指缩放，布局视角默认开"简化网格"（性能档）。

## 4. 镜头风险与工程约束（防"视角特效卡 bug"）

| 风险 | 约束 |
|---|---|
| 相机状态机错乱 | 显式状态机（TP/FP/Blueprint/Page），只允许白名单转移；每次转移有超时兜底，超时强制回 TP |
| 后处理叠加 | **单条后处理管线**，蓝图/FP 只改参数不改链路；禁止运行时 AddComponent 式后处理 |
| 特效预算 | 分层 VFX 预算（屏幕占比/粒子数上限）；蓝图视角自动降级（关景深/动态模糊/体积光） |
| 相机穿模 | 弹簧臂 + 球扫 + 室内自动拉近；蓝图用正交，避免透视穿模 |
| 晕动症 | FP 可选关摆动；蓝图过渡 ≤150ms；提供"固定相机"辅助选项 |
| 联机一致性 | 建造/抹除/地形变化**服务端权威**（或房主权威），客户端只做预测与回滚；地形网格用确定性 ID |
| 测试矩阵 | 相机×区域×特效×网络延迟 的自动化冒烟（每版跑）；重点测：追杀中切蓝图、抹除中切 FP、布局中被打断 |

**实现顺序**：先做 TP/FP 两态稳定（R1），再加蓝图（R2），最后加非对称专属镜头（R3）；每步都跑相机冒烟测试。

## 5. 其他玩法也加"地形层"

- **对称 3v3/5v5**：三路馈线=三条可变形通道；推线=登记，拆校筑=抹除；校筑组合改变兵线路径（设墙分流、搭桥抄后）。
- **PvE 抢修**：抢修前可"预布置"（搭脚手架/接地垫/临时屏障），用时间换安全；BOSS 战会破坏地形。
- **剧情章**：册页地形可"翻页"改变（翻页=换布局），把叙事与地形绑一起。
- **卡组副模式**：机架上的元件组合决定"自动战场"的地形（串联出桥、并联出双通道）。
