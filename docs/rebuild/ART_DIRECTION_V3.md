# 美术方向 V3：从「科技感」转向「生活质感 + 自然之美」

日期：2026-11-09　状态：候选方向，待主策划选定（可多选/混搭）
配图：`work/store/art-v3b/palette-board.png`（五套色板）、`A-warm-film-sheet.jpg` 等调色试片（仅验证色调与质感基线，**不代表最终建模**）

## 0. 先说结论

前三套方向（深青赛博 / 浅色纸张 / 紫粉二次元）的共同问题：**都在「界面换皮」，没有回答「世界看起来像什么」**。而主策划真正的诉求是「生活原本的质感」与「真实世界的风景美感」——这不是 UI 主题能解决的，是**世界美术方向**问题。

因此 V3 不再给「主题皮肤」，而是给 **5 个世界美术方向**（含参考作品、实现路径、成本、风险、适合《第七校验》的部分），并给出推荐：**方向 2（写实自然主义）+ 方向 1（温暖生活手绘）的混合**——用写实光照/天空/植被打底，用轻度手绘化处理（去锐利、去塑料感、加空气感）保证可控产能；UI 采用「纸张/黄铜仪器」的浅色生活化材质，而非霓虹面板。

## 1. 五个候选方向

### 方向 1：温暖生活手绘（吉卜力式）「日子本身的光」

- **观感**：下午四点的斜光、木窗、晾衣绳、菜市场、蒸汽、猫在台阶上；人物动作略夸张，表情手绘；天空是水彩渐变，云有形状。
- **参考**：《千与千寻》《魔女宅急便》《二之国》《Ni no Kuni》《Dordogne》《A Short Hike》《Cozy Grove》。
- **技术**：NPR 卡通渲染（分层 toon ramp + 手绘描边 + 手绘贴图）＋烘焙光照＋体积雾＋暖色调 LUT；模型面数中低，靠手绘贴图出细节。
- **成本**：中（需要美术手绘能力或外包；程序化可先做 60%）。
- **优点**：最贴「生活质感」；情绪亲和；对教学界面友好（纸张/木头/黄铜）。
- **缺点**：风景「壮阔感」弱；大规模地形难做出真实自然美。
- **适配**：主城街区、生活区、室内、NPC 日常。

### 方向 2：写实自然主义（电影风景）「一座真实的海边山城」

- **观感**：《荒野大镖客 2》的自然光、《死亡搁浅》的雾与地表、《塞尔达：旷野之息》的远景层次；真实天空盒、体积云、海面反射、草地风动、岩石风化；色调偏自然，夕阳/阴天/雨后各有色彩脚本。
- **参考**：《Red Dead Redemption 2》《Death Stranding》《The Long Dark》《Firewatch》（色块化处理）、《Sable》（线稿+平涂的轻量版）、《原神》的远景（风格化写实）。
- **技术**：PBR + 高度雾 + 体积光 + 程序化天空 + 植被/岩石/水面 shader；大量使用扫描材质/贴图；地形用 heightmap + splatmap；性能靠 LOD/流式加载。
- **成本**：高（素材与调优都贵），但**可以借资产包与程序化材质把成本压到可控**；桌面/主机优先，移动端降级。
- **优点**：风景美感上限最高；Steam 玩家对「画面」的第一眼判断最吃这套。
- **缺点**：风格化不足，容易和「教学游戏」气质割裂；美术产能要求高；移动端吃力。
- **适配**：大世界、离岛、远景、过场。

### 方向 3：水彩绘本（北欧/独立）「一页会呼吸的插画」

- **观感**：纸纹、水痕、低饱和、边缘不规则；像一本可以走进去的绘本；天空是大块晕染；人物简笔但有表情。
- **参考**：《Dordogne》《Sable》《Gris》《Monument Valley》《Behind the Frame》《书行者》。
- **技术**：手绘贴图 + 屏幕空间纸纹/水痕后处理 + 低多边形；阴影用色块而非写实；可程序化生成纸纹与边缘。
- **成本**：中低（程序化可覆盖大部分）；产能高。
- **优点**：最有「艺术辨识度」；对独立团队最友好；和「校验单/册页/铜印」的叙事质感天然契合。
- **缺点**：动作与战斗表现力弱；大世界探索的「真实风景」感不足。
- **适配**：教学面板、回忆/过场、秘境、小说插图。

### 方向 4：胶片纪实（阴天/长焦）「一座被拍下来的城」

- **观感**：阴天、低对比、颗粒、暗部偏青、窗户里的暖光；像纪录片；真实但克制。
- **参考**：《Firewatch》的色块、《Sable》的线稿、是枝裕和电影、滨口龙介、《The Long Dark》。
- **技术**：写实基底 + 低饱和 LUT + 颗粒 + 暗角 + 柔光；成本比方向 2 低（可用现成资产），靠调色统一。
- **优点**：性价比最高；与「工程/检修/雨水/旧城」题材气质最合；移动端压力小。
- **缺点**：不够「明亮幻想」，对 Steam 首屏吸引力弱于方向 2；需要好的天空与雾来救。
- **适配**：主城、雨天、夜戏、制度线。

### 方向 5：明亮幻想（二次元开放世界）「原神/无限暖暖式的明快」

- **观感**：高饱和、干净、远景层层叠叠、天空有奇观（浮岛/极光/巨构）；角色可爱、动作舒展。
- **参考**：《原神》《无限暖暖》《鸣潮》《幻塔》《光·遇》。
- **技术**：三渲二 + 卡通描边 + 风格化天空 + 体积光；模型/贴图中高；特效丰富。
- **成本**：中高（特效与角色产能）；对「生活质感」帮助有限。
- **优点**：最「卖相」；用户群最大；和桌宠/共鸣体设定契合。
- **缺点**：容易滑回「科技/二次元」的套路；真实风景美感弱；和「校验/册页/铜印」的朴素质感冲突。
- **适配**：宣传首屏、桌宠、共鸣体、幻想层（校验神殿）。

## 2. 推荐：2 + 1 混合（写实自然打底，手绘化收边）

- **世界**：写实自然主义的地形/天空/水面/植被（方向 2），但**材质做手绘化处理**（降低锐度、加纸纹/笔触、色彩分层更少），避免「塑料写实」；远景用「色块+空气透视」压平，减少面数。
- **城市**：主城用方向 1 的生活细节（晾衣、摊贩、蒸汽、猫、木窗暖光），但光照与天空仍走方向 2 的真实自然光。
- **UI**：纸张 + 黄铜 + 深青墨（不是霓虹玻璃）；教学面板像「检修手册/册页」，HUD 像「仪表铭牌」。
- **秘境/回忆**：方向 3 水彩绘本，作为「册页里的世界」，形成强烈对比与记忆点。
- **夜戏/雨天**：方向 4 的胶片纪实调色，作为章节情绪。
- **避免**：大面积霓虹、赛博招牌、纯深色 UI、发光描边堆叠——这些是主策划明确否掉的「科技感」。

**为什么混合可行**：一个世界不需要只有一种笔触。原神的蒙德（明亮幻想）与层岩巨渊（暗色写实）并存；我们的「现实层（流明域）」用写实自然 + 生活手绘，「册页层（校验神殿/回忆）」用水彩绘本，正好把「世界是校验单」的设定变成美术语言。

## 3. 落地路径（不改玩法，先换「皮」与「光」）

1. **R1-A 色彩与光照**（1–2 周）：程序化天空（黄昏/阴天/雨）、高度雾、体积光、LUT；先让现有场景「好看 30%」。
2. **R1-B 材质手绘化**（1–2 周）：把现有 5 类街景材质（砖/混凝土/波纹板/木/帆布）重做成手绘贴图；降低金属度与高光，加纸纹/污渍/笔触。
3. **R1-C 生活陈设**（1 周）：晾衣绳、菜摊、木箱、猫、自行车、蒸汽/炊烟粒子；主城一条街先做样板。
4. **R1-D 远景与地形**（2 周）：heightmap 地形 + 色块化远景 + 海面/雾，先把「出城看风景」做成卖点。
5. **R1-E 移动端降级**（1 周）：LOD/纹理分级/后处理降级。
6. 验收：同一机位「改造前/后」对比 8 张 + 1080p60/720p30 帧率表 + 五维评分。
