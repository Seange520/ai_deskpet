# 美术融合方案 V1（A 骨 · B 光 · C 内景）

> 用户决定：不二选一，**全部融进去、合理分配**。本方案把三种方向拆成「骨/光/内景」三层，按场景分配，避免混搭成脏。
> 基线：`A_STORE_AND_TRAILER_PLAN_V1.md`、`ART_DIRECTION_AND_QUALITY_DECISION_V1.md`（已按本方案修订）。

## 一、三层分工（先定层，再定场景）

| 层 | 来自 | 职责 | 具体做法 |
| --- | --- | --- | --- |
| **A 骨（结构/界面）** | 暖色胶片/纸面晴光街 | 决定「这是什么材质的世界」：纸、墨、黄铜、陶土、木头 | UI 默认浅色纸面；标题宋体/正文思源黑；黄铜细线 1px；卡片纸纹；按钮像纸压印 |
| **B 光（时间/户外）** | 写实自然电影感 | 决定「几点、什么天气、看向哪」：金色黄昏、雾、逆光、长影 | hub 与街景主光低角度暖金（2700–3200K 视觉）；雾色暖灰；远景青紫极光只作冷点缀；阴影拉长 |
| **C 内景（情绪/奇观）** | 水彩绘本北欧 | 决定「进入册页/回忆/塔内」时的画面语言：晕染、留白、湿边、低饱和 | 册中境、塔内、回忆闪回、章节插画；SVG/图版用湿边+纸纹+淡水彩叠色；仅这些场景允许脱离「实拍感」 |

## 三、执行顺序（每轮只动一层）

1. **B 光**：hub + R1 主光暖化、雾色、曝光统一（1 轮）。
2. **A 骨**：完成剩余页对比度（代码工坊说明、排位已改委托板）；统一纸纹/黄铜线。
3. **C 内景**：给 3 张「回忆类」SVG 加湿边版本（K1-04 降压、AD-06 帧缓冲、IC-04 逻辑门各选 1 张试水）。
4. **胶囊/截图/预告**：按最终光重拍。

## 四、反面清单（融合不是全都要）

- 不在同一屏混用「纸面 UI + 霓虹描边 + 水彩底」三种语言：一屏最多 A+B 或 A+C。
- 不把 C 的水彩用到可测量界面（读数区必须清晰可核对）。
- 不在 Steam 商店页用 AI 概念图冒充实机；概念片只发社媒并标注。
- 不为了「电影感」压暗教学文字；对比度优先于氛围。

## 五、验收

- 每场景截 1 张 1080p；检查：光源方向一致、纸面 UI 对比度 ≥ 4.5:1（正文）、无霓虹残留、无 AI 素材冒充实机。
- 用户五维门槛：视觉渲染 ≥4.5 才交付；本轮目标视觉 4.6/5。
