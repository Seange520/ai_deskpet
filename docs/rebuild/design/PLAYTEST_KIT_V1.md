# 试玩包 V1（10–20 人封闭试玩）

## 给试玩者的三句话

1. 这是一款「修街 + 学电路」的单机游戏，核心不是打怪，是把一条街一盏一盏修亮。
2. 你不需要懂电，课程会从万用表、串联、通路开始教；不会就先退出，不用硬扛。
3. 请边玩边吐槽：哪一步卡住、哪句话看不懂、哪个画面难受，都是有效反馈。

## 入口

- Web（免安装，推荐）：`/?mission=r1&quality=3`（抢修委托）；`/?quality=3`（主界面）
- 教学：主界面「校验册」→ 课节；第一章「会呼吸的路灯」
- 爆炸图：`/?exploded=1`；工坊页「全零件说明书 →」
- Android：`seventh-checksum-v0.9.8-android-debug-v15.apk`（覆盖安装保留存档）
- Windows：`TheSeventhChecksum-desktop-win64.zip`（解压双击 exe，Tier3 2× DPR / 4096 阴影）

## 10 个任务（不用全做，按顺序尽力）

1. 进主界面 → 打开「委托板」，看三张单，选一张接。
2. 完成「熄灯的晚餐」：诊断 → 测量 → 修复 → 合闸。
3. 完成后，回到教学面板，从街上的现场课去开一节课。
4. 打开「校验册」→「星图」，找到你已掌握的课节，说说看不看得懂。
5. 进「街坊工坊」，点「全零件说明书 →」，拖动爆炸图、点选两个零件看说明。
6. 开一节 K1-01（欧姆定律与串联分压），做完观察/学习/实践三段。
7. 故意做错一次诊断（连错两次），看游戏怎么反馈；记下感受。
8. 在「保护者档案」里改一次外观（颜色/天线），看是否生效。
9. 手机上试一次：摇杆走两步、拖动转视角、点一次「跳跃」。
10. 退出再进，看进度是否保留；关闭声音再开，看 BGM/音效是否正常。

## 15 个问题（每项 1–5 分 + 一句话）

1. 第一眼：这个界面像什么？第一印象是「精致」还是「土」？
2. 不用教程，你知道先点哪里吗？
3. 抢修流程（诊断→测量→修复→合闸）哪一步最迷惑？
4. 万用表读数/档位，你觉得像真表还是像游戏？
5. 教学课节的文字量和节奏，能接受吗？哪一段想跳过？
6. 星图/任务链，看得出「下一步该学什么」吗？
7. 爆炸图对你理解「桌宠由什么组成」有帮助吗？（1=没帮助，5=很清楚）
8. 画面：最丑的一处 / 最好看的一处，各一句话。
9. 手机上：字太小？按键够大？卡不卡？
10. 声音：BGM/音效是加分还是干扰？
11. 修好一盏灯后，有没有「我做成了」的反馈？够不够？
12. 有没有哪一句台词/文案让你出戏或看不懂？
13. 如果明天只能改一件事，你希望改什么？
14. 你会推荐给同学吗？为什么？
15. 一句话总评（可以很毒）。

## 回收格式

- 文本即可：任务编号 + 分数 + 一句话；画面问题请截图（Win+Shift+S / 手机截图）。
- 汇总给指挥官：按「阻断（玩不下去）/ 难受（体验差）/ 想要（增项）」三栏整理，阻断优先修。

## 边界与诚实说明

- 这是 v1.0 单机内测：无账号、无联机、无排行榜；4v1 在下一个大版本。
- 教学仿真是等效模型，不代表真实电路；真接线请断电、验电、按老师/手册来。
- 数据只存本机（localStorage），换浏览器/清缓存会丢存档。
