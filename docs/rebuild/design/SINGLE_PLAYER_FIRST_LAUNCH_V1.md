# 单机优先上线路线 V1.0

> 依据主策划 2026-11-10 决策：**前期用户不会特别多，先上线单机模式；核心主打玩法 4v1 晚一个版本推。**
> 关联：`CORE_GAMEPLAY_V3_REGISTRATION_WAR.md`、`LAUNCH_SCOPE_V1.md`、`ART_DIRECTION_AND_QUALITY_DECISION_V1.md`、`PROJECT_LINE_STATUS_AND_DRIFT_AUDIT_V1.md`。

## 一、决策与含义

- **v1.0 = 单机（离线可玩）版本**：全部内容本地运行、无服务端、无账号强制、无联机匹配。
- **v2.0 = 4v1 非对称**：空页对局、联机、匹配与观战整体后置一个版本；对称 3v3/5v5 再后。
- 理由：4v1 的联机成本（服务器/匹配/网络同步/反作弊/平衡）远高于内容验证所需；单机版本可以最快拿到「教学 + 抢修 + 世界」的真实反馈，用反馈决定 4v1 的具体形态，避免在无人验证的玩法上先烧联机基建。

## 三、v1.0 上线脊梁（必须全部达成）

1. 新手 30 分钟闭环：开机 → 序章 → 第一单抢修 → 计分 → 回到教学 → 第二单。
2. 教学可验证：接线/读数/判断/提交，全部有可复算证据；无「看视频就算学会」的课时。
3. 世界可信：晴光街一条街 1080p 50 DC 内、≥120fps（Tier3）、阴影/材质/灯光完成。
4. 美术一致：纸面 + 暖光 + 内景水彩，无赛博残留（旧硬件实验室页已 A 化）。
5. 双端可跑：Web（桌面 + 移动）、APK、桌面 zip，启动无白屏/无 console error。
6. 存档稳定：任务进度、课节进度、档案、设置本地持久化，清档有提示。
7. 商店素材齐：7 尺寸胶囊 + 6 截图 + 90 秒实机预告 + 文案三件套（中文为主）。
8. 无致命 bug：E2E 全绿、单测全绿、压力测试（连续 3 单 + 刷新恢复）通过。

## 四、技术取舍（v1.0 冻结项）

- 不引入服务端；不做账号/云存档；不做实时联机；不做排行榜（委托板为本地记录）。
- AI 零保留本地规则版（不接隐藏 API），避免上线期成本与合规风险；对话只覆盖已写脚本。
- 存档键保持现有 `sparkmate.checksum.*` 前缀，未来迁移时做版本迁移函数。
- 包体：Web 首屏 ≤ 3MB（gzip），APK ≤ 40MB，桌面 zip ≤ 150MB；超出即触发资产 LOD 调整。

## 六、4v1 后置说明（v2.0）

- 保留设计文档与角色/校筑/地形规则，不在 v1.0 代码里预留联机接口（避免无谓复杂度）。

## 七、风险与对策

| 风险 | 对策 |
| --- | --- |
| 单机内容量不足以支撑「正式版」 | 以「教学 36 节 + 三单 + 爆炸图 + 22 章档案」为内容盘；定价 6–12 元或免费+支持者包 |
| 4v1 后置导致期待落差 | 商店页与预告只展示单机内容；4v1 作为「未来更新」提及，不承诺日期 |
| 移动端性能不足 | Tier2 720p 已实测 125fps；低端机降 LOD/关阴影 |
| 桌面 Electron 首次启动被杀软误报 | 提供 zip 绿色版 + 安装说明；后续签名 |
| 用户量小、反馈慢 | 先做 20–50 人封闭试玩；公开版加匿名崩溃上报（可选开关） |
