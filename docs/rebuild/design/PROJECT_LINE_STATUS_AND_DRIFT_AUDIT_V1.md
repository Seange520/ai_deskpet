## 二、跑偏审计（按「是否因链长/上下文大而偏离」逐项判定）

1. **⚠️ 视觉重构挤占核心玩法（中度）**：过去 24h 做了 4 批 UI、主题系统、A 基线、模块改名；核心玩法仍停在 R1 灰盒。
   → 纠偏：**先定主线**（R1 竖切优先，V3 只做设计不写码）；每轮只允许 1 个视觉批次 + 1 个玩法增量；视觉必须服务「可读性/证据链」。
2. **⚠️ 双线并行导致上下文膨胀（中度）**：小说 17 章 + 游戏重构 + 平台包体同时推进，单轮信息量大。
   → 纠偏：文件即记忆——每线固定锚点（本文件、`NOVEL_*`、`R1_MISSION_ACCEPTANCE`、`A_STORE_AND_TRAILER_PLAN`）；每轮开始读锚点，结束更新锚点；单轮只动 2 条线。
3. **⚠️ 模块「换名未换内容」（轻度）**：校验册/街坊工坊/誊写房/委托板已改名，委托板是全新功能，但街坊工坊/誊写房内部仍是旧硬件/代码模拟。
   → 纠偏：下一轮把「街坊工坊」改造成「街坊报修台」（委托式接线/测量），「誊写房」改造成「誊抄与校订」（代码=改册），文案与目标对齐世界观；不新增页面。
4. **⚠️ 爆炸图与实操课脱节（轻度）**：原型是独立页，还没进 AD-01。
   → 纠偏：先接 AD-01「先认零件」段作为可交互图版（lazy + Tier2 降级），再谈实物 BOM。
5. **✅ 验收口径在收紧**：E2E 67/单测 457/13 项 R1 验收/8 维审稿，均有可复现脚本。
   → 保持：每次交付必附「脚本名 + 通过数 + 截图 + SHA」。
6. **✅ 未发现「忘记初心」型跑偏**：教学仍是主线，小说服务世界观，商业化未越过教学红线（不卖战力/答案）。
   → 保持红线：抽卡只外观、教学必可验证、不剧透。
