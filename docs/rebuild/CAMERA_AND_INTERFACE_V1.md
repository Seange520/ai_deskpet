# 视角与界面设计 V1（CAMERA_AND_INTERFACE_V1）
《第七校验·流明域》· 2026-11-10 · 回答"上帝视角放置 or 第三人称 or 第一人称"

## 0. 先拆问题

你问的其实是三件事：
1. **主视角**：玩家平时怎么"看世界"？
2. **放置/建造**：校筑与布线用什么视角？
3. **不同玩法要不要不同界面**？

我的答案：**一套相机，四种镜头模板，按"当前在做什么"切，不按"模式"切。** 模式只决定默认镜头与 UI 皮肤。

## 1. 四种镜头模板

| 模板 | 视角 | 用在哪 | 为什么 |
|---|---|---|---|
| **A 沉浸镜头（FP）** | 第一人称 | 抢修工具操作、测量、拆灯座、被空页追 | 手/表/钳的特写=沉浸与紧张；读数直接怼脸，教学自然 |
| **B 跟随镜头（TP）** | 第三人称越肩（默认） | 探索、跑位、联机、看角色/皮肤 | 看得见自己与队友，联机可读性最好；也最适合卖外观 |
| **C 蓝图镜头（God/Top-down）** | 高机位俯视，可旋转 | 校筑部署、布线、看馈线/登记率、MOBA 战术 | "放置类"的爽点：一眼看清全局电路；但不是主控视角 |
| **D 册页镜头（2D/正交）** | 平面册页 | 剧情章、册中境、卡组副模式 | 与"世界是一份册"同构；省成本、有辨识度 |

**主控默认 = B（第三人称）**；A 是"工作模式"；C 是"建造/战术模式"；D 是"叙事/卡牌"。

## 2. 各玩法的默认与切换

| 玩法 | 默认 | 一键切换 | 界面形态 |
|---|---|---|---|
| **PvE 危机抢修** | B 跟随 | 按住「工具键」→ A 沉浸（测/拆/接线时自动进 A） | 极简 HUD：三件工具+危险提示+队友状态；不显示血条，显示"安全/带电/超限" |
| **非对称 4v1·校验员** | B 跟随 | 长按「蓝图」→ C 俯视看登记区 | 册页式小地图（登记=实体/未登记=留白），校筑槽位环 |
| **非对称 4v1·空页** | A 沉浸（猎手第一人称） | 按「册页」→ C 全图抹除预览 | 无 HUD 干扰，画面里只有"能抹/不能抹"的高亮 |
| **对称 3v3/5v5** | C 高机位第三人称（Dota 式越肩俯视） | 滚轮拉近→ B 跟随 | 三路馈线图+安培+技能/大招冷却+登记率 |
| **剧情章** | B 跟随 + 过肩对话 | 取证时自动 A（看表/拓印） | 纸质手记+证据链；无任务清单 |
| **校筑/布线** | C 蓝图（半透明网格） | 松手回 B | 元件插槽/安培/登记半径预览 |
| **卡组副模式** | D 2D 俯视（机架网格） | — | 卡牌+机架+自动结算 |
| **册中境** | A/B 混合（漂浮页空间） | — | 水彩+留白+手写 |

## 3. 为什么主控选第三人称，不选第一人称

- **联机可读性**：4v1/5v5 里队友要看见彼此位置与动作，第一人称会丢信息。
- **角色与皮肤**：抽卡/外观的前提是"看得见角色"；第一人称把最大的一笔收入挡在屏幕外。
- **教学**：第三人称看得见"手在做什么"、工具在哪个位置；第一人称容易晕、门槛高。
- **空页例外**：猎手用第一人称（像 DBD 杀手/第五人格监管者），压迫感最强，且不需要看自己皮肤（可卖"视角特效/手部皮肤"）。

## 4. 为什么"放置/建造"用蓝图镜头，而不是上帝视角主控

- 上帝视角适合"看电路/摆建筑"，不适合"跑位/抢修/被追"。
- 所以做成**可开合的蓝图镜头**：按一下，世界减速/暂停（单人）或半透明覆盖（联机），看网格→摆校筑→松手回第三人称。
- 这就是你说的"上帝视角放置"的正确位置：**它不是主玩法，是建造模式**；就像《辐射4》造家、《城市天际线》看电路，但退出后立刻回到动作。

## 5. 相机规格（可执行）

- TP：距离 3.2–4.5m，俯角 12–18°，FOV 60–70，越肩偏移 0.35m，碰撞回弹，室内自动拉近。
- FP：眼高 1.62m，FOV 75–85，工具手持占屏 25–35%，头部摆动可关。
- 蓝图：正交/近正交，高度 18–30m，可 90° 旋转，网格 0.5m，登记半径/馈线高亮。
- 切换：≤150ms 过渡，无黑屏；联机时 C 模式不暂停（只做半透明覆盖）。
- 晕动症：TP 默认，FP 可选；提供"关闭头部摆动/降低 FOV/固定相机"。
- 移动端：默认 C+TP 混合（小屏更难 TP），建造用双指缩放蓝图。

## 6. UI 语言（与六区美学绑定）

- 同一套组件，按 `data-zone` 换皮（见 `GAME_ADAPTATION_V1.md` §3）。
- UI 位置：左下=工具轮盘，右下=动作，顶部=登记率/目标，右上=小地图（册页式）。
- **不做的**：不做满屏血条/伤害数字；不做任务清单堆叠；不做"战力"面板。

## 7. 一句话

**平时第三人称跑世界；动手时第一人称做工具；造东西时切蓝图上帝视角；读故事/打牌时进册页 2D。**
四种镜头各司其职，不互相抢主控；每个玩法只决定"默认用哪个 + UI 换哪套皮"。
