# 小说→游戏适配 V1（GAME_ADAPTATION_V1）
《第七校验·流明域》· 2026-11-10 · 主策已认玩法 V3，进入"真正适配"阶段

## 0. 原则（四条）

1. **小说是正典，游戏是它的"可玩重写"**——不魔改设定，但允许把内心戏改成可操作的选择。
2. **每章只适配"能玩的那部分"**：3 个场景 + 2 个知识/机制点 + 3 件物证（沿用合成蓝图 §6 的"游戏化清单"）。
3. **教学藏在后果里**：不出现"答题过关"；玩家用工具做对/做错，城市给出不同反应。
4. **分区美学**：不同区域换 UI 语言与场景语言（见 §3），不是全游戏一套皮肤。

## 1. 模式对应（四层）

## 4. UI 形态（按玩法分）

- **抢修 HUD**：万用表/钳/听针三件，实时读数+危险提示；极简，把屏幕留给场景。
- **拓册 UI**：册页式小地图（登记区=实体，未登记=留白/纸纹），校筑槽位环。
- **剧情章 UI**：纸质手记 + 拓片拼合；不显示血条/任务清单，只显示"证据链"。
- **对称 UI**：三路馈线图 + 安培资源 + 技能/大招冷却。
- **卡组副模式**：元件卡+机架网格（Backpack Battles 式）。

## 5. 首版适配顺序（R1）

1. **ch01 抢修教学局**（单人 15 分钟）：丁九街口→工坊→灯柱，三件工具，验电/断闸/复电，双评分。
2. **ch03 合作局**（2 人）：井+表箱，跨接与井封。
3. **ch05 非对称教学局**（1v4，AI 空页）：井边换封场景改"抹除/登记"。
4. **ch06 剧情章**（单人）：进塔查册，证据链拼合。

## 6. 与小说的同步规则
- 每章小说定稿（R 严审通过）→ 出"游戏化清单"（3 场景/2 机制/3 物证）→ 进适配待办。
- 游戏内不出现"小说没写"的设定；需要新设定先回写 `CANON_DECISIONS_V1.md`。
- 教学知识点只从"章内可验证的读数/证据"出，不额外加课。
