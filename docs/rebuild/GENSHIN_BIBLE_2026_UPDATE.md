## 二、2026 年新增/强化的六类设计

1. **空间操作型关卡**（空之神殿）
   - 不再是「大世界一景」，而是把「空间」本身做成解谜对象：特殊交互改变区域空间，
     隐藏道路与秘密浮出。
   - 对我们的启示：教学解谜也可以「操作空间/时间/信息层」，而不是只加新地图。
   - 实现上适合做「关卡切片 + 独立规则集」，不必等整张大地图完成。

2. **文明切片式内容组织**
   - 神殿内以璃月书院、须弥沙上楼阁、枫丹/稻妻风格分馆呈现不同文明。
   - 这是「低成本高辨识度」的内容复用：同一套底层规则，换成文明皮肤+专属交互。
   - 对我们的启示：七柱章节可以各做一个「校验分馆」，共享引擎、独立规则与美术语言。

3. **反应体系继续外扩**（月结晶）
   - 把既有反应（结晶）转成新反应（月结晶），并围绕它做角色/配队/环境。
   - 对我们的启示：教学系统的「七柱」不必每次新造，可做「旧规则的新组合」，
     降低学习成本、提高深度。

4. **UGC/创作者工具持续迭代**（星々の幻境/千星奇域）
   - 大厅容量、特效工具、技能编辑自由度、UI 素材持续开放。
   - 对我们的启示：如果要做「玩家自制校验关卡」，必须先有稳定的关卡 DSL 与
     审核/回放/评分基础设施；不要一上来做全能编辑器。

5. **节庆版本的「情绪呼吸」**
   - 月之八这种夏日/归乡/千灵节版本，承担老角色回收、轻松叙事、社交传播。
   - 对我们的启示：主线之外每 3–4 个「校验周期」放一个低门槛、高情绪、可分享的节庆版本。

6. **长线收束期的内容策略（7.x）**
   - 从「不断开新国」转向「回收伏笔、重访旧地、终章推进」。
   - 对我们的启示：立项时就要写「结局与回收表」，避免无限扩张；每一卷都要有可收束的闭环。

## 三、旧圣经中需要修正的判断

1. 「国家=新机制」仍然对，但**2026 的增量更多来自『旧地图的空间重构』与『旧反应的新组合』**，
   而不是单纯新国家。
2. 「大地图越大越好」需要修正为：**密度 × 可重访性 × 空间层次** 比面积更重要；
   空之神殿证明「垂直/切片/可变形空间」可以用更小面积换更高记忆点。
3. UI/启动界面不是装饰：空之神殿与登录界面的呼应说明**品牌记忆点可以跨系统复用**
   （我们也可以让「启动画面」与「最终关卡」互为镜像）。
4. 抽卡与商业化仍需坚守我们的红线；原神的反应/角色体系可学，**付费结构不学**。

## 四、对《第七校验》的直接落点

- **空之神殿式终章**：把「第七校验」做成一座可进入的「校验神殿」，内部是七个文明/七柱切片，
  玩家用已有工具逐层校验，最终面对「这次过不了」的真相。
- **空间操作**：把「读数/接线/时序」之外新增一类「空间校验」解谜（移动参照物、改变量程视野、
  折叠路径），对应「量程/基准/环境」的教学点。
- **月结晶式组合**：七柱能力不新增第七种，而是允许「旧工具×新场景」组合出高阶解。
- **节庆版本**：每个大章之后做一次「灯会/千灵节」式轻量版本，回收 NPC、给情绪、做传播素材。
- **收束表**：从 R1 起就维护「伏笔—回收—章节」三列表，结局先写。
