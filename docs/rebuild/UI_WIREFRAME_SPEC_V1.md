# UI 信息架构与线框规范 V1（原神式焕新）

> 依据 `design-pivot/GENSHIN_DESIGN_BIBLE_V1.md` 的页面/键位/面板结论 + `PIVOT_GENSHIN_V1.md` 边界，给 Codex 卡 02 的逐屏规格。所有尺寸以桌面 1920×1080 为基准，移动端 390×844 为上限约束。

## 一、设计 token（与现有 `visual-v2.css` 对齐，扩展原神式语义）

```
--ui-bg-elevation-0: 深空底 #0e1420
--ui-panel:          glass 暗底 (opacity .82 + backdrop-blur 18px)
--ui-panel-strong:   面板聚焦态 (opacity .94)

--ui-line-strong:    rgba(255,255,255,.32)
--ui-text:           #f4f7fb

--ui-radius-s: 10px  --ui-radius-m: 14px  --ui-radius-l: 20px
```

## 二、启动流（无「进入按钮」）

```
[0.0s] 黑场 + 品牌微光（logo 六边形呼吸）         — 600ms
[0.6s] 世界从雾中拉远：大陆剪影 + 极光 + 城市光点   — 2.4s（相机 fov 75→60）
[3.0s] 标题淡入：THE SEVENTH CHECKSUM / 第七校验   — 1.2s
[4.2s] 标题化开，相机下压至主角头顶 1.5m           — 1.6s
[5.8s] 主角落地/站起，HUD 自边缘滑入，可操作         — 无按钮，任意键/触屏可跳过读条
```
- 读条只做「资源就绪」事实：`加载地区/编译着色器/同步档案`，完成即落地；失败给「离线继续」按钮（existence fallback）。
- 桌面端 Esc 可跳过至落地；移动端点击右上「跳过」。

### 教学面板规格（重写重点）

```
左侧 88px 竖标签：委托｜星图｜档案（图标+竖排文字，选中高亮）
右侧内容区：max-width 1180px，上下留白 48px
委托流程：
  1) 委托单卡：标题（编号+名称）/ 委托方 NPC 头像 / 目标三行 / 「接受委托」
  2) 教学七段：任务简报 → 观察 → 原理学习 → 动手演练 → 校验 → 迁移 → 完成
     · 每段左侧时间线节点，右侧内容；段间「下一段」；可随时「暂离」
  3) 观察段：左大图（SVG/3D 截图），右读数面板
  4) 演练段：内嵌仿真（现有 39 个组件换皮）
  5) 完成：结算动画（证据→档案→共鸣+1），按钮「返回世界」
```
- 移动端：竖标签折叠为顶部横 tab；内容单列；仿真横向滚动。

## 五、组件与交互规范

- 按钮三态：默认（glass）/ hover（外发光 + 上移 1px）/ disabled（opacity .45，禁 cursor）。
- 输入框：聚焦时 1px accent 环 + 内发光；错误时 danger 环 + 行内提示。
- 列表项：hover 背景提亮 4%，选中左缘 3px accent 条。
- 弹窗：居中 640px，遮罩 rgba(4,8,14,.62)+blur 6px；Esc 关闭。
- 键盘：全流程可纯键盘操作；焦点环 2px accent 可见。
- 无障碍：对比度 ≥4.5:1（正文）、≥3:1（大字号）；`prefers-reduced-motion` 时关闭视差/呼吸。

## 七、验收口径（Codex 卡 02/03 共用）

1. 任何界面 0 console error，0 横向溢出（390/768/1440/1920 四档）。
2. 主要交互（面板开合/切 tab/进课节/进设置/切主题）全键盘可达。
3. HUD 节点数量 ≤ 12，任务卡不与小地图重叠（截图核对）。
4. 首屏从加载到可操作 ≤ 8s（本机 dev，quality=3）。
5. 旧入口（进入按钮/枢纽卡片）不再出现；旧页面 404 不出现。
