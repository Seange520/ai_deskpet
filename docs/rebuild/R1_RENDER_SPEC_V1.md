# R1 渲染原型技术规格（三渲二）V1

> 给 Codex 卡 01 的落地版规格。目标：在现有 React Three Fiber 工程里加一条**可开关的三渲二管线**，先在一个测试场景验收，不破坏旧 PBR 路径。参照 `GENSHIN_DESIGN_BIBLE_V1.md` 08 渲染章节与 `PIVOT_GENSHIN_V1.md` 边界。

## 一、验收场景

`?toon=1&scene=garden`（新增路由参数，dev-only）：一座 200m×200m 测试庭院 —— 草地、石阶、3 栋幻想建筑、1 个机械遗迹、主角 + 桌宠、昼夜开关。旧 `?quality=` 路径不受影响。

## 二、三渲二管线

1. **基础着色（Toon）**
   - 漫反射：硬边两段式 `NdotL` 阈值 0.45，冷阴影色 `#5a6f9a`，暖受光 `#ffe6c4`。
   - 高光：单点硬高光，`pow(NdotH, 64) * 0.6`，仅金属/皮肤层启用。
   - 阴影：级联阴影贴图 2048，软边 2 级；主角与桌宠单独高精度阴影。
2. **描边（Outline）**
   - 方案：背面扩张（inverted hull），法线外扩 0.02–0.035（按相机距离自适应），描边色 `#1a1f2e`，透明度 0.85。
   - 角色/桌宠描边更细（0.012），建筑 0.03；禁用屏幕空间描边（移动端成本高）。
3. **天空与大气**
   - 程序化天空：顶 `#7fb6ff`、地平 `#ffe9c9`、极光带 `#7cf2d0`（夜间）；2 层云（噪声滚动）。
   - 雾：指数雾，密度 0.0025，色随天空地平色；远景山体用高度雾。
4. **后处理（桌面开、手机降级）**
   - Bloom（阈值 0.9，强度 0.35）、轻微色差（0.0006）、暗角（0.18）、胶片颗粒（0.03）。
   - 色彩分级：曝光 +0.05、对比度 1.06、饱和 1.02、阴影加青、高光加暖。
   - 手机：仅 Bloom + 暗角，关闭颗粒/色差。
5. **昼夜**
   - 24 分钟一轮；关键色彩 LUT 由代码插值（黎明/正午/黄昏/夜）；夜间点亮窗户与灯柱（emissive + Bloom）。
   - 教学联动：白天测光、夜间测电（读数面板提示「日冕模式」）。

## 三、性能预算

| 项 | 桌面 (RTX 3060 / M1) | 手机 (骁龙 8 Gen2 级) |
| --- | --- | --- |
| 分辨率 | 1080p @60 | 720p @30（动态分辨率） |
| Draw call | ≤ 300 | ≤ 180 |
| 三角面 | ≤ 2.5M | ≤ 900k |
| 后处理 | 全开 | Bloom+暗角 |
| 阴影 | CSM 2048 ×2 级 | 1024 ×1 级 |
| 内存 | ≤ 900MB | ≤ 450MB |

## 四、交付物

1. `src/render/toon/`：`ToonMaterial.tsx`（或 .jsx）、`OutlinePass`、`Sky.tsx`、`PostFX.tsx`、`toonPreset.mjs`（参数表）。
2. 参数面板（dev-only）：`?toon=1&debug=1` 显示可调滑杆（阈值/描边宽/曝光/雾密度），并支持「复制参数 JSON」。
3. 测试场景 `src/render/scenes/GardenTest.jsx`（灰盒资产即可）。
4. 证据：4 张对比截图（旧 PBR vs 三渲二，白天/夜晚）+ 性能表（`work/acceptance/r1-render/perf.md`，记录 draw call/三角面/帧率/内存）。
5. 开关：`?toon=0` 回旧路径；`npm run build` 通过；E2E 67 不破。

## 五、验收口径

- 与参考图（研究文档 08 章示例）对比：边缘干净、阴影有级差、天空有层次、夜间灯光有辉光。
- 主角/建筑在逆光与夜景下仍可辨识（描边不断裂）。
- 切昼夜无闪烁/漏光；手机模拟（CPU 4x throttle）仍 ≥25fps。
- console 0 error；包体增量 ≤ 80KB（gzip）。

## 六、参考与边界

- 只学习「三渲二 + 明亮幻想 + 大世界远景观」的**做法**，不复制原神模型/贴图/UI。
- 资产：R1 用程序化材质 + CC0 贴图（Poly Haven/Kenney），正式资产 R2 后再替换。
