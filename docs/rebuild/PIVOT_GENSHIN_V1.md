## 0. 边界与红线（必须先对齐）

1. **风格靠拢 ≠ 资产照搬**：可以学习原神的卡通渲染语言、信息架构、节奏与情感设计；不得使用米哈游角色/场景/UI 贴图/音乐/文本，不得像素级复刻其界面。所有资产原创或使用可商用授权资源（CC0/购买授权），并留授权记录。
2. **教学内核不丢**：本作仍是「可验证的工程教学」。大世界是壳，课节证据链（测量/接线/仿真/代码/项目）是骨；五维评分（视觉/叙事/性能/教学/可接受性）≥4.5 的交付门槛不变。
3. **零抽卡/零战力付费承诺不撤回**（外观付费可另议，见商业化文档）；不做 FOMO 与强制社交。
4. **合规**：国内正式发行需版号；在取得版号前，国内只做内测/TestFlight 式小范围传播，不公开收费；海外 Steam 可先行（需软著/主体/税务）。小说出版走正规平台签约，避免侵权与敏感内容。

## 1. 目标形态

- **单机向开放世界 × 工程教学**：启动即进入世界（无「进入游戏」按钮），首次加载用电影化过场 + 进度提示，加载完成直接落地。
- **美术方向**：明亮幻想 + 机械遗迹（三渲二卡通渲染，天空/云/极光保留辨识度），摒弃霓虹赛博。
- **世界规模**：9 个旧岛整合为「流明大陆」+ 群岛：主城（熔炉城）、野外区域（晶脉荒原、回响海岸、齿轮林）、秘境（教学地下城）。
- **内容骨架**：序章（教学）+ 七柱章节（对应七层知识）+ 专业支线（IC/AI）+ 终章；每章 1 主城/2 野外/1 秘境。

## 2. 技术路线（Three.js / R3F 既有栈上升级）

- 渲染：Toon/PBR 混合着色器、描边（后处理）、屏幕空间 AO、Bloom、DOF、Color Grade、体积光/云、昼夜与天气系统。
- 世界：分块流式加载（Region/Chunk）、LOD、遮挡剔除、实例化植被/岩石；烘焙光照贴图 + 动态主光。
- 角色：卡通材质 + 表情/口型 + 布料/头发轻模拟；桌宠沿用现有系统做「战宠/伙伴」。
- UI：设计 token 系统 + ReactBits 动效组件 + 自研面板框架；双端响应式（桌面 16:9 / 手机 19.5:9 竖横屏）。
- 性能：桌面目标 1080p60（中端独显），手机目标 720p30（中端机）；包体走基础包+资源包（Asset Pack 已有底座）。

## 3. UI/UX 设计系统（对标原神的信息架构，原创视觉）

- 主界面：顶部中央体力/状态、左上圆形小地图（可展开大地图）、右侧任务追踪、底部中央血条/元素/快捷栏（本作改为「仪表/工具/技能」三栏）、右下交互键与跳跃/冲刺、左侧摇杆（移动端）。
- 功能键：角色（C）、背包（B）、地图（M）、任务（J）、教学（L）、设置（Esc）；社交/好友（O，弱化）。
- 面板：全屏半透明渐变底、左侧竖排大标签、右侧内容区、顶部面包屑；统一 200/300/400 字重与 4/8/16 间距栅格。
- 动效：面板 240ms 弹性进场、列表交错 40ms、按钮 hover 光斑、确认音效；移动端手势返回。
- 键位自定义与手柄支持（后期）。

## 4. 大世界设计

- 地图尺寸：目标 4km×4km 主大陆 + 3 座离岛（可扩展）；传送锚点/七天神像式「校验塔」；体力/攀爬/滑翔。
- 探索循环：观察 → 解谜（电路/逻辑/工艺）→ 获取材料/图纸 → 回到工作台制作 → 推动剧情。
- 任务系统：主线（七柱）/支线（NPC 委托）/日常（每日校验 3 条）/探索（宝箱/秘境）。
- 战斗（可选轻量）：工具与桌宠技能，非数值碾压；教学关卡以「正确操作」为胜负判定。

## 5. 教学改造

- 旧 36+12+18 节课节全部保留为「世界任务/秘境课程」，UI 呈现改为任务对话 + 课堂面板双形态。
- 证据链：每次测量/接线/仿真写入冒险手册（原「档案」），可导出为学习报告。
- 诊断→路线推荐→星图改「天赋树/命座式」视觉，但语义仍是掌握度。
