## 4. 问题与返修项（不阻断集成）

1. `SM_Wall_Window_Roof` 默认正面朝 -Y；组装时统一 `rotation.y = Math.PI` 或建组时翻转。
2. 墙模块背板/侧面为纯色平板：贴街时背面临街需遮挡（用相邻模块或加高围挡）。
3. 缺「门/招牌/转角」件：R1-A3 补三件（`SM_Door`、`SM_Sign_Board`、`SM_Wall_Corner`）。
4. 进引擎需环境贴图/半球光 + ACES 色调映射，否则 PBR 发灰（集成任务处理）。
