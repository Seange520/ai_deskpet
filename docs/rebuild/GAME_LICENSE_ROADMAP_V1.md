# 版号与国内合规推进方案 V1

> 主策划指令："版号向前推进"。本文给出在「学生团队、资金有限」前提下可执行的现实路径与材料清单；不承诺时间，只明确动作与依赖。

## 一、先厘清概念

- **软著**（计算机软件著作权登记）：版权证明，已准备材料（源码前后各 30 页、说明书 30 页）。1–3 个月，免费/代理 300–800 元。
- **游戏版号**（网络游戏审批）：国内正式上线收费运营的前置许可，由版署审批、省局初审；单机游戏同样需要（作为"移动游戏/客户端游戏"申报）。
- **ICP 备案/许可证**：网站备案（域名）+ 经营性 ICP（收费时）。
- **ISBN（出版物号）**：纸质出版物；游戏若含大量文本出版成书需出版社支持。

## 二、现实路线（分阶段）

### 阶段 0：海外先行（0–3 个月，不依赖版号）

- Steam 上架：需要 Steam Direct $100、软著/主体、税务信息（W-8BEN）、银行账户；不需版号。
- 海外收费可行；国内用户可通过加速器访问，但不在国内做付费推广。
- 同步准备：隐私政策、EULA、未成年人保护提示、内容自审报告。

### 阶段 1：主体与备案（1–3 个月）

1. 注册公司（个体户也可，但版号申请通常要求企业）：经营范围含"软件开发/数字内容服务"。
2. 软著登记（若公司名义申请，需著作权归属协议）。
3. 域名 ICP 备案；若做官网+下载，需公安备案。
4. 开通对公账户、支付通道（Steam 无需国内支付；国内渠道需要）。

### 阶段 2：版号申请（6–12 个月，需耐心）

材料清单（省局/版署口径，具体以受理窗口为准）：

1. 游戏出版申请表（出版单位/运营单位/研发单位信息）。
2. 游戏作品文字脚本（主线剧情全文或分章梗概，≥1 万字）。
3. 游戏玩法说明（核心循环、系统、付费点、防沉迷）。
4. 美术资源清单与截图（角色/场景/UI，需原创声明）。
5. 音乐/音效授权证明（原创或 CC0/购买授权）。
6. 软著证书、营业执照、ICP 备案。
7. 内容自审报告（无政治/色情/暴力/赌博/迷信等违规内容；含"工程教学"教育属性说明）。
8. 未成年人保护方案（实名认证、时长限制、充值限制、家长监护）。
9. 测试账号与安装包（按省局要求提供）。

流程：研发单位 → 出版单位（需有出版资质的出版社/游戏出版公司）→ 省局初审 → 版署终审 → 批复文号 → 上线备案。

### 阶段 3：国内上线（版号后）

- 渠道：TapTap、好游快爆、应用宝、华为/小米/OV 商店；需版号+软著+ICP。
- 付费：接入合规支付；未成年人保护 SDK。
- 运营：内容更新需版本备案（重大变更报备）。

## 三、成本与人力估算

| 项目 | 费用 | 周期 |
| --- | --- | --- |
| 公司注册+记账 | ¥3,000–8,000/年 | 1–2 周 |
| 软著（自办/代理） | ¥0 / ¥300–800 | 1–3 月 |
| ICP 备案 | 免费 | 2–4 周 |
| 版号（自办，含出版单位协作） | ¥0–30,000（出版服务费浮动） | 6–12 月 |
| 未成年人保护/实名 | 按 SDK 计费 | 1 周接入 |

## 四、风险与替代

- 版号周期长、政策变动：**不要 all-in**；海外 Steam + 国内内测是最稳组合。
- 若走"教育软件"而非"游戏"申报：可能规避版号，但不得含游戏化收费与抽卡；本作含剧情/战斗要素，不建议此路径。
- 与高校/大创合作：可通过学校科研成果转化/出版合作降低主体门槛，但需明确 IP 归属。
