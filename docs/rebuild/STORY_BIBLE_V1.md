# 主线故事圣经 V1《流明域七章》

> 依据小说 ch01–ch03（序/零/赫菲/衡/准/秤）、`V2.0` 世界观与 `PIVOT_GENSHIN_V1.md`。定义游戏主线章节、区域任务链、伏笔回收节奏，与小说互为表里（游戏为主线，小说为正典扩展）。

## 一、核心命题

- **表层**：一座「会呼吸的城市」停摆了，玩家作为见习校验员逐条修复。
- **里层**：有人把「测量」变成了统治工具——读数被搬、时间被拿、册上有名才算人。玩家要做的不是修机器，是**把被篡改的标准改回真的**。
- **结局方向**：不是打倒大魔王，而是**让塔重新可被校验**——主角把自己的名字写进册子第一行，然后让所有人都有权查塔的账。

## 四、任务链模板（每个区域）

```
主线委托 1（教学入门，K 课 1 节）
  → 支线委托 ×2（练习/材料，可选）
  → 主线委托 2（异常升级，K 课 1–2 节）
  → 区域事件（限时/环境变化，1 个）
  → 主线委托 3（迁移/综合，prove + transfer）
  → 修复反馈（世界变化）→ 下一区域
```

- 每区域主线 ≥6 节教学课；支线委托给材料与图鉴。
- 「检修委托」外壳统一：委托方、目标、时限、证据、验收人。
- 世界反馈必须可见：灯亮、水通、桥连、雾散、居民回来。

## 六、与小说的关系

- 小说卷一是「序的第一年」；游戏主线是「可玩的那一年」，事件同源、细节互补。
- 小说中已出现的测量链（5.83 V/0.19 A、5.62 A/2.14 V 等）作为游戏课节的数据基准，保证「小说里能算出来的，游戏里能测出来」。
- 冲突时以游戏可玩性为准，小说做说明性调整；正典文件名 `CANON_LEDGER`。
