# 大世界重做方案 V1（原神式大陆 + 教学任务映射）

> 目标：把旧「9 座岛 + 传送门」的赛博空间，重做为一座可连续探索的明亮幻想大陆（流明域）+ 3 座离岛。本文定义分区、地标、任务映射、流式加载与验收，供 Codex 卡 04 与后续内容迁移使用。

## 一、总体形态

- 世界尺寸：**4 km × 4 km** 主大陆（无缝），外海 3 座离岛（各 400–600 m 直径，乘船/滑翔抵达）。
- 海拔：海岸 0m → 丘陵 80m → 七柱高地 220m；主城在中央盆地，一座「会呼吸的钟塔」为视觉锚点。
- 昼夜：24 分钟一轮（游戏内），光影分级；教学读数受「日冕/夜巡」影响（白天测光、夜晚测电）。
- 移动：冲刺/攀爬/滑翔/游泳；桌面 WASD + Space/W，移动端摇杆 + 动作键。
- 无加载进入：启动即落地（卡 03），区域切换用「隧道/雾门/传送锚点」，不出现读条页。

## 三、地标密度与引导（原神式）

- 每 300–450m 一个「可交互点」（宝箱/检修点/锚点/采集），主路径每 150m 一个视线锚点（塔/光柱/烟）。
- 传送锚点 12 个（主大陆 9 + 离岛 3），首次靠近解锁；解锁有短演出。
- 七柱：每柱一座高塔，塔顶是章节 Boss 解谜场；柱间用「光路」在空中可见，作为远景观引导。
- 探索奖励：材料（用于 DIY/外观）、图鉴条目、共鸣点；**不产出战力数值**。

## 五、技术实现

1. **场景组织**：`src/world/regions/<region>/`（地形 heightmap + splat + 实例化植被 + POI 定义 JSON）。
2. **流式加载**：以 256m 网格分块；主角 2 块内高精度，2–4 块低精度；卸载 4 块外。桌面 60fps / 手机 30fps 预算。
3. **任务状态**：`src/quest/` 数据驱动（前置条件 = 课节掌握/共鸣等级/物品），触发点用 POI 引用。
4. **教学接入**：委托单 → 打开现有 `LessonRunnerV2`（换皮），完成后回写 profile 与共鸣；世界内出现「修复后的变化」（灯亮/水流/桥通），形成正反馈。
5. **导航**：小地图实时渲染 region 贴图 + 图标层；大地图 M 缩放 1×/2×/4×。
6. **性能预算**：同屏 draw call ≤ 300；角色 ≤ 60k tri；远景靠 impostor/雾；手机端关后处理与阴影贴图降级。

## 七、风险

- 地形与美术产能：先用程序化地形 + 模块化建筑灰盒，正式资产后补；**不要阻塞教学可玩性**。

- 范围膨胀：先做 R-01/R-02 两条区域，验收后再复制到其余区域。
