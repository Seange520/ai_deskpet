# 发行架构 V2：Steam 国际版 + 国内「共创分支包」

日期：2026-11-09　状态：方案设计（主策划已定方向，待拍板细节）

## 0. 主策划已定口径（本方案的前提）

- **国际版**：以学生个人可执行的 Steam 发行为最优解；**不做抽卡/随机物品**；营收靠 DLC（外观、支持者包等）；**不阉割核心剧情、大世界游玩、教学模块**。
- **国内版**：现阶段不做公开商业发行；做一版**完全免费的分支包**给自己和同学玩，功能可与国际版不同（可加好玩的新功能），但**不能有任何与营收挂钩的风险**；为以后国内上线或转卖版权做铺垫。
- **付费设计**：可以设计付费抽卡/直售游戏币/外观包等**系统与界面**，但分支包**不开放真实充值**，改用礼包码发放代币（内部「破解版」式体验）。
- 最终国内版可能成为主包体，但现阶段只做技术准备。

- 两版存档键分开：`sparkmate.checksum.profile.v1`（国际）／`sparkmate.checksum.branch.v1`（内部），避免串档。

## 2. 内部版「礼包码 + 代币」设计（无真实充值）

### 2.1 代币

- 名称：**校验券**（Checkmark Token）。
- 来源：礼包码兑换（仅内部）；不接任何支付 SDK；无广告；无倒计时/制造焦虑。
- 消耗：外观（灯具皮肤、桌宠外壳、界面主题、工牌样式、贴纸）、便利（筛选项扩展、星图标记）——**不卖战力、不卖答案、不卖剧情**。

### 2.2 礼包码

- 格式：`SC-XXXX-XXXX-XXXX`（大写字母数字，避免易混字符 0/O/1/I）。
- 生成：离线脚本 `scripts/gen-redeem-codes.mjs`，HMAC-SHA256 签名 + 面额 + 批次号 + 过期时间；只生成码表 CSV，**码表不进游戏包**。
- 校验：游戏内用内置公钥/共享密钥校验签名与面额，校验通过后写入本地代币账本 `sparkmate.checksum.tokens.v1`（`{ balance, redeemed: [{code, amount, at}], history }`）。
- 防刷：同一码只能兑换一次（本地账本去重）；码面额与批次白名单；离线也能兑。
- 管理：主策划/我持有码表；给同学发「一张码 = 一次礼包」，可打印/微信发。

### 2.3 商店界面（两版共用，仅支付方式不同）

- 页签：外观 / 主题 / 桌宠 / 支持者。
- 每件显示：预览、价格（代币）、已拥有、来源标注（「礼包码解锁」）。
- 国际版结算按钮 → Steam 支付（后续接 Steamworks MicroTxn 或 DLC SKU）；
- 内部版结算按钮 → 「使用礼包码」输入框 + 余额；**没有任何真实支付入口**。

## 3. 国际版 Steam 商业设计（学生最优解）

- **本体**：¥38（首发 -10%），EA 8–10 周后上线；Demo 免费（前 2 章）。
- **DLC（无抽卡）**：
  - 支持者包 ¥68（原声 + 数字画册 + 工牌样式 + 名字进「维护者名录」）。
  - 外观包 ¥6–18/个（灯具皮肤、桌宠外壳、界面主题），全部纯外观。
  - 原声集 ¥18。
- **不做**：章节扩展包（会割裂剧情）、随机箱、战力/答案售卖、限时 FOMO。
- **Steamworks 前置**：$100 上架费、商店页素材（已有 kit）、Depot 上传脚本（已演练）、隐私政策、AI 内容声明（美术/文本使用 AI 辅助的披露）。
- **收入预期**：按 `STEAM_LAUNCH_ECONOMICS_V1.md`，回本线 100–400 份；不把盈利当短期目标，先积累评价与愿望单。

1. 软著：材料已生成（`work/deliverables/copyright/`），以个人名义申请「第七校验游戏软件 V0.9.8」。

4. 国内渠道：TapTap/好游快爆（免费版先行）、WeGame（后续）。
5. 分支包就是「免费预热版」：完全免费、无水印外的商业化内容、可收集反馈。

## 6. 合规红线

- 内部版：**零真实支付、零广告、零公开分发、零售卖**；水印与「禁止售卖」声明；不接入任何支付 SDK。
- 国际版：Steam 政策（不卖随机物品、AI 内容披露、退款政策）；不向未成年定向营销。
- 两版都不卖：战力、抽卡、答案、剧情锁、排行榜优势。
