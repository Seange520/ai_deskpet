## 二、推荐组合（30 天可执行）

1. **主更：豆瓣阅读（非独家电子）** 或 番茄「非独家」——中文读者基本盘；同时 **爱发电镜像** 保留完整版权与打赏入口。
2. **英文同步：Royal Road**（每周 2 更）+ **Patreon**（$3/$5 档：提前章、设定集、壁纸）；Ko-fi 一次性打赏。
3. **短篇试水：知乎盐选** 投 1–2 个单元剧（不签长篇买断），测读者反馈与转化。
4. **导流闭环**：每章末「作者的话」只提「同名游戏开发中，官网/QQ群」；B 站/抖音发 60–90 秒剧情向视频（AI 概念片标注「概念影像」），主页挂游戏官网。
5. **预热节奏**：免费章 20 章 → 读者群 → 发 R1 试玩/Demo 邀请 → 收集愿望单/预约；游戏上线前 4 周集中更新 + 预约活动。
6. **回本目标（现实）**：爱发电 10–30 人×¥10–30/月 + Patreon 5–20 人×$3–5 + 少量打赏 ≈ 每月 ¥300–1,500；覆盖 API 费用（本会话约 ¥43）与部分美术/服务器成本，不指望平台分成。

## 三、合同红线（逐条写进补充协议）

1. **授权范围**：仅「简体中文信息网络传播权（非独家）」；不含改编权（影视/游戏/动漫/有声/出版/衍生品）。
2. **期限**：3–5 年，到期自动回归；作者可提前 30 天书面终止。
3. **地域**：中国大陆（海外权利自留）。
4. **改编权自留**：任何改编须作者另行书面授权，收益归作者；平台仅有「优先洽谈权」且不超过 30 天。
5. **署名权**：笔名与真名署名方式由作者定；不得代签。
6. **断更/下架**：不得设惩罚性违约金；作者可自主下架，平台 7 日内下线。
7. **数据与读者**：作者有权获得阅读数据；不得限制作者在自渠道发布（非独家）。
8. **结算**：月度对账、最低结算额、逾期利息。

> 操作：签约前让平台把「授权范围/期限/改编权/终止」写进合同正文；拿不准花 ¥200–500 找版权律师做一次合同审查，比事后维权便宜。
