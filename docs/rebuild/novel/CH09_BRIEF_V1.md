# CH09 简报：第九章《补页人》（暂名）

> 版本：V1（2026-11-10）。依据 R8《NOVEL_CRITIQUE_CH08_R1.md》§7.1 五接口。
> 上一章：ch08《衡的页》4,793 字，已过 R8（8.55；P0 清零）。

## 1. 本章任务

1. **补页归属**：补页单页主衡／补页人序／见证空。塔认页主还是补页人？序会不会因为「补页人」三个字第一次在册上有了位置（哪怕一栏）？这是 ch09 最该回答的问题。
2. **第三把钥匙与十七日刻号机**：序已知道 17 日机子动过、铅屑未发黑、油新、锉痕亮；钥匙三把＋裁纸人后门钥匙。ch09 让序排查「第三把在谁身上」，并让**一一七**第一次落地（封号从一一七起）。嫌疑人：衡、铜角、第三持有者、裁纸人。
3. **衡刮名的后果**：她把补页单「衡」刮了，纸背压痕还在；候册初八页只剩纸根。塔会不会把「衡」写回？「补上了，你就回去了」——她回去成了谁？若写衡「不记得自己的名字」，就是 A14 代价兑现。
4. **小满的第四个名字**：「明天我写第四个。」「写谁？」「不告诉你。」——第四个是谁（序/迟/她自己/一一五换写法）？这句话是 ch09 的钩子，不能丢。
5. **零的删格代价落到序身上**：ch08 零用「男孩的手几天」换一格存三个衡；ch09 若再删一格，代价必须落在序身上（例如序忘记小满的门缝、或忘记一个具体约定），否则「格数代价」变抽象设定。

## 2. 七场结构（每场 500–900 字）

1. **有号第一日**：序发现自己被写在补页单上（补页人栏），街坊/册吏/塔的反应各不相同；有人开始叫他「补页的」。
2. **第三把钥匙之一**：序查裁纸人（腰上钥匙、不在册、十七日裁纸无单）；她只承认「钥匙是后门的，不算三把里的」。
3. **第三把钥匙之二**：铜角与衡各有一把；序用排除法逼近「第三把在谁身上」；一一七第一次出现（新封落地在某个对象上）。
4. **衡不记得名字**（真静场）：衡回塔办交接，序在井边等她；她回来时，说不出自己的名字，但认得「衡」这个字；真静场写物（井、绳、灯、纸）。
5. **补页人栏的后果**：塔里来人对单；序的「补页人」栏被要求改成「见证」或划掉；序第一次面对「上册」的诱惑（有号=被算）。
6. **小满的第四个名字**：小满写第四个名字，折纸不给看；序问「写谁」，她说「写一个不还的」。
7. **章末钩子（代价钩）**：序发现零又删了一格——他忘记了一个具体约定（例如小满让他「灯亮三下就回来」）；他站在街口，听见灯亮三下，却不记得是谁让他听。

## 3. 正典与规则

- 封号从一一七起；「准」不出现；迟不正面出场（只留物证/口信）。
- 序无号；「补页人」栏是否等于「有号」——A13 未注册者规则与 A14 代价要自洽。
- 衡：A14 代价兑现（不记得自己名字，但认得字）；她补的页是初八那一页。
- 零：只报数，不解释；再删一格必须付代价，代价落在序的记忆。
- **测量段窄口径 ≤25%**（A20）；单段工程动作 ≤3 句。
- 语言红线同 V2 §7；本章至少 1 处真静场（场四）；四种钩子轮换，本章用「代价钩」。
