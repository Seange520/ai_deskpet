# CH08 简报：第八章《衡的页》（暂名）

> 版本：V1（2026-11-10）。依据 R7《NOVEL_CRITIQUE_CH07_R1.md》§7.1 五接口。
> 上一章：ch07《补页》4,394 字，已过 R7（8.66；P0 清零）。

## 1. 本章任务

1. **半个「衡」字落地为衡自己的页**：ch07 已让序拓出半个「衡」字（F26）；本章不喊答案，让序把三个出处（ch05 收条、册背封签、签单）串起来，意识到被抽的页里有一页是衡的——她开侧门、带序进册房、要一张空白单，是在补自己。
2. **「提前」的「原来」给一半**：工单无日期、无印、册纸、水印「校」；序查闭塔年的纸从哪道门出来、谁有权把校验从周期里抽出来。给「原定日子」的一半（例如：原定立冬后第七日；或「七百年周期里的霜降」），不一次给完。
3. **第三把钥匙排查**：侧门 16 日开、18 日封；17 日谁动了刻号机？三人嫌疑（衡/铜角/未知持有者）；序袋中缺角封钳是清白证据（F27）。第三把钥匙持有人前三场露面一次、不点名。
4. **男孩的十天与无名一栏**：推进一件（手开始收口 / 衡来核对单子 / 序被叫去按手印补一栏），让「无名」的代价可见。
5. **小满的第三个名字**：她写第三个名字；序问她写谁；她把纸折起来不给看。与「迟的一一五牌、三天到期（第 17 日）」发生关系。
6. **章末钩子（反转钩，不用工单/灯/钟）**：序在侧门或册房后间发现——被抽的六页里，有一页的压痕是衡的签名；而衡当天把自己的名字从一张单上刮掉了。最后一句落在「她也在补页」或「她刮得比塔干净」。

## 2. 七场结构（每场 500–900 字）

1. **第三天**：迟的三天到期；序去回响塔外等，等到的是衡。衡要拓片（她要保「册上现在没写」不被翻案）。
2. **交易**：序用拓片换一次册房后间查看；衡条件再加一条「你替我再签一张单」。
3. **纸从哪道门出来**：序查册纸/水印「校」/毛边断针眼，追到「不盖印的那道门」；第三把钥匙持有人在此场露面一次（不点名，只留一个动作或物件）。
4. **刻号机**：册房后间，刻号机罩布新掀过；序看字口、深浅、台阶，确认 17 日有人用过；衡不否认，也不说谁。
5. **男孩的一栏**：衡来核对单子；男孩手背收口；序被要求补按一个手印；「无名」的代价第一次落到具体动作（例如：衡在「无名」旁添「认得脸，叫不出名」）。
6. **小满的第三个名字**：小满写第三个名字，折纸不给看；序问「写谁」，她说「写你也不对，你没有号」。
7. **她也在补页**：序在册房后间/侧门封背面发现压痕里有衡的签名；回街时衡在井边刮一张单上的名字；章末反问「她刮得比塔干净」。

## 3. 正典与规则

- 封号从一一七起（若出现）；「准」不出现；迟不正面出场（只留物证/口信）。
- 序无号：四道门只开两道；衡的签名与小满的纸仍是绕行手段。
- 衡动机：只签事实不签结论；她要保「册上现在没写」不被翻案；本章揭开她补自己的页。
- 零：只报数不解释；ch07 已删三格，本章可再删一格但必须付代价（报错一次或漏报一次）。
- **测量段按窄口径 ≤25%**（A20）；单段工程动作 ≤3 句；宽口径仅趋势参考。
- 语言红线同 V2 §7；每章 1–2 处静场、3 句可抄；四种钩子轮换，本章用「反转钩」。
