# 第五章 第十四天

第十四天，天没亮，卖炭的男人就蹲在工坊门口。序认得他。

他怀里抱着一块炭，炭上放着一张纸，纸是塔里的废单，背面白。他见序开门，站起来，又蹲下去。

「你写。写我闺女。」

「写什么？」

「她叫小满。六岁。怕黑，睡觉要开一条门缝。」

序认得这几个字。他写过。那天男人说：满出来的满。



序看着他。男人的手很粗，指甲缝里全是黑，捏着那张纸，捏得很紧。

「写了，她就在册上？」

「写了，就在纸上。」

序进屋拿笔。笔尖钝了，在鞋底蹭了蹭。男人说，他写：小满，六岁，会数到二十，怕黑，睡觉要开一条门缝。

写完，男人把纸折成很小的一块，塞进贴身衣袋。

「纸在，她就在。」

他朝街口走。走了几步，又回头。

「册上会加吗？」

序没有答。男人也没有等，走了。

天亮了。井盖上多了一个封。

不是他压的那个。他压的那个还在：压线钳的牙印，横一道，竖一道，像一块粗布。多出来的那个挨着它，铅是亮的，边上没有牙印，中间一个号——一一四。

两个封，穿在同一个封耳里。谁也没剪谁。

序蹲下去，先看封耳，再看井盖，再看封耳。

「他们没开井。」零在他肩上说。

「没开，压了封。」

「压给谁看？」

「给街上看。」

今天是立冬。塔里换册。街口的木牌上，那张告示还在，四个角铜钉钉着，最下面一行：因街市未靖，换封提前。原定立冬，改在霜降后第八日。表、井两行，复封。

初八那天，塔里来过。序在窗后看见那辆车，两个人，一只木匣，一把封钳，在井边停了不到一炷香。他没出去。出去，就是「聚众」。

井盖是铸铁的，一圈锈。封耳在盖子南边，巴掌大，一个六毫米的孔。塔里那个封的铅丝穿过孔，两头压成饼。饼面二十一毫米，厚三分。序那个也是饼，比他那天的硬，牙印里积了灰。

他伸手，把塔里那个饼转了转。转不动。

「压得紧。」零说。

「紧，才是新铅。」

序裁三指宽碳纸，压在饼上，用铅笔侧棱擦。第一遍纸破了；第二遍只出来一半；第三遍削钝笔尖，擦两回，纸上浮出「一一四」。

他把拓片夹进工作本。本子里还夹着另一张：七年前那个封的拓片，边角发毛，号也是一一四。

「两张一样。」零说。

「号一样。」

「号一样，铅不一样。」

七年前那个封，他剪下来，没扔。铅饼在他手心里，边上有一道剪口。饼面发灰，指甲刮下去，刮出一层粉。

塔里那个，指甲刮下去，是一条卷。

「一个掉粉，一个掉卷。」

「一个七年，一个六天。」

序把新旧两个饼并排放在井沿。他没有再量：旧饼他量了七年，比新饼软。

拓片收好，他做了一个决定：趁天没大亮，把井盖掀一条缝，先看一眼线。

他不想在三十七个人面前第一次就翻车。他想先看一眼，把数拿在手里，再叫人。

井盖很沉。他撬开两指宽，手电照进去，光柱里浮着灰。表笔伸进去，碰在接头上，读数跳了一下：零点零二。

他换镊子去够第二个点。表笔尖擦过井壁的铁，一道白光蹿出来，打在虎口上。他往后一仰，坐在地上。表笔掉进井里，「咚」。

虎口上一条白，很快起了一圈红。

他坐在那里，听着自己的心跳。街上有狗叫。他把手按在膝盖上，按了很久。然后他站起来，把井盖推回原位，把撬棍上的土擦干净。

回工坊，他用冷水冲手，拿布缠上。血渗出来，把布洇透一块。

赫菲在炉子边看见他的手。

「开了？」

「开了。」

「数呢？」

「表笔掉了。」

老人没有骂他，也没有叹气。他从炉子上拿下水壶，倒了一碗，让他把布解开。

「皮焦了。」老人说，「肉没事。」

他把一块旧布浸了凉水，缠上去。

「你要开，先断线。」他说，「不断，你开的不是井，是命。」

「我断了。」

「断了还打？」

序没说话。老人看了他一眼。

「断了还打，就是线没断干净。」他说，「你封了这么多回，也跟你爹一样，先动手，后想。」

序把碗放下。

「今天酉时，我要开。」

「手这样，开什么？」

「开。」

老人没有再劝。他把水壶放回炉上，坐下，把烟袋摸出来，装了一锅，点上。烟从他们中间慢慢升上去。

「你这一回，少说话。」他说，「话多，人就多；人多，塔就多。」

他把拓片摊在炉台上。赫菲看了一眼拓片。


「塔里那个，新？」

「六天。」

老人把铅条从口袋里摸出来，捏了捏。

「你要在人前开，不在人前说。」

「人到了，再说。」

「他们初八来过。」

「来过，压了封，没开井。」老人说，「没开井，就是没验。没验，就是不敢验。」

「他们不敢验什么？」

「验井里那根线。」赫菲说，「线在，七年前的火就在。」

酉时还早。序把七样东西一样一样摆在井沿上：铜尺、碳纸、纸片、铜螺母、钳表、手电、印泥盒。

街口的表箱上，也换了一个封。一一三。铅是亮的。

序没有动它。他在箱外量了一遍：进线五点六二，出线五点六二。表针压在零上。

「表在箱里。」

「表在箱里，数在箱外。」

供电单还在内袋里，折了四折。三十天，剩十六天。

「单子上还有十六天。」

「井已经换过一回了。」

「两张纸，两个日子。」

「哪张算？」

「哪张都不算。」零说，「井在中间。」

年轻的复核员来的时候，肩上还是那只木匣。他站在井边，看了一眼两个封，脸白了一下。

「谁让你动的？」

「我没动。」

「初八那天，我来过。上头让加封。」

「加封不开井？」

「没开，封什么？」

他停了两息。

「封个样子。」

序看着他。初八那天，压了封，没开井，没验线。

「册上写了？」序问。

「册不在我这儿。」

那人从袖子里摸出一张折好的纸，递过来。

「处理单。私封，损封，聚众。三条。」

「损封？」

「你砸了塔里的封。」

「我砸的是我自己的。」

「塔里的也砸了。」那人说，「纸上写，封面无损。你砸了，就是损。」

「你还没看。」

「我不用看。我写，就是看。」

零在他肩上开口。

「你写，是你写。封上有没有坑，是封上有没有坑。」

那人看了它一眼。

「你记的数，改一改。塔前那段，三十七个人，作废。」

「作废，还是删？」

「删。」

「删不了。改了，数还在，纸没了。纸没了，明天算账，算不平。」

「我给你平。」

「你平的是你的账。我这儿两栏。你一栏，我一栏。」

那人把纸收回去。

「你要怎么样？」

「你写四个字。已核，作废。签你的名。」

「作废也是记。」

「删了，纸上少一段；作废，纸上多一段。你要哪段？」

那人把纸折起来，塞回袖子。

「上头看得见。」

「看得见，才是记。」

他站起来，往街口看。日头偏西，街那头来了一辆车。

衡来的时候，车上带了两样东西：一本铜包角的册子，一只封钳箱。她下车，先看井，再看序，再看井。

「两个封。」她说。

「两个。」

「哪个是你的？」

「压线钳那个。」

她蹲下去，看了很久。她没有伸手。

「牙印深。」她说，「压了三回。」

「第一回没压透，第二回偏了，第三回才合上。」

「塔里那个，一回。」她说。

「一回，六天。」

她打开册子。册子很厚，纸边发黄，最后一页还空着。她翻到井那一页。

「七年·霜降。井。一一四。压封：准校验。」

她往下指。下面一行是空的。

「初八没写。」

「初八塔里来过。」

「来过，没写。」

「没写，就是没复封。」

「封在井上。」

「封在井上，册上没写。」

「册上没写的封，不算封。」她说。

「那井上这个，不算？」

「不算。」

「不算，你们还压？」

「压的人，不是我。」

她的指套在册子边上敲了两下。

「初八谁来的？」

「他。」衡抬了抬下巴。

那个年轻的复核员站在车边，没过来。

「开箱。」序说。

「箱是塔里的。」

「箱在街上。封上有号，号在册上。」序说，「开箱之前，先写条件。」

他从本子上撕下一页，铺在井盖上，写：时间、温度、进出线读数、表针、封印号、见证。写完，推过去。

「签。」

衡看了很久，签了一个字：衡。她用封钳剪了表箱上的封，箱门开了。

箱里有一张卡：霜降后第八日。表：复封，一一三。井：复封，一一四。底数：〇·〇〇。压封人：——

序把卡举高，念到「压封人」，停住。

「这一栏，空着。」

「外派也有名。」

「名在册上。册上没写初八。」

衡把卡收进册子。序把钳表卡在进线上。五点六二。出线，五点六二。表针，零。

「线从表前过去了。七年前就过去了。」衡说，「封的是箱，箱里有跨线。」

序看着那两根线。铜的，压接，灌锡，热缩。和井里那根一样的手艺。七年前一个人接的，七年后一个人封的。

「册上写哪儿？」他问。

「写数。」

「数是多少？」

「零。」

「线在，数是零。」

「数是零。」衡说。

「复封有复封的次序。」她说，「验封，剪封，压封，记册。」

「验井呢？」

「封是封封的。井在册上。」

序没接话。他把旧饼放在井沿上，把铜螺母捏到尺顶。

「一尺高。一两二。三回。」

他松手。螺母落下去，砸在旧饼上。没有印子。

他把铜尺、螺母、旧饼递给修鞋老头。

「你来。」

老头把锥子插在腰上，蹲下去，砸了三回。旧饼上还是没有印子。

「你来。」序又把东西递给面坊女人。女人砸了三回，也没有。

「这个，谁来？」序指着塔里那个封。

没有人动。衡站在井边，没有动。

「你不来，我来。」

他砸了一下。饼面凹下去一小块。男孩凑过来，数了数卡在尺和饼之间的纸片。

「六张。」

序看着衡。

「你按一下。」

「按了，算损封。」

「不按，算不知道。」

衡把铜指套摘下来，用拇指按在饼上。铅凹下去一点。她抬起手，拇指上有一圈亮。

「损封。」她说，「一枚。我按的。」

那个年轻的复核员往前走了一步，又停住。

「六张，是几天？」面坊女人问。

「初八到今天，六天。」

街上有风。井沿上的纸片被吹起来，男孩伸手按住。

后排一个穿旧棉袍的老头也伸了手，替男孩把纸按住。他的手指很干，指腹上有一层黄。

「压接、灌锡、热缩。」他说，「三层。七年前没第三层。」

序抬头。人堆挡着，他只看见一顶旧帽子。

「你怎么知道？」

「线埋过。」

老头说完就退回去了。男孩回头找他，找不着。

「开井之前，先断。」序说。

「断了，街上黑。」

「黑半个时辰。」

「井里有线，线通着十一户。不断，开盖就是带电。」

「你做过？」

「没做过。所以先断。」

衡看了他一眼。

「断。」

序走到表箱前，把总闸拉下来。铜片落进槽里，「咔」的一声。

街黑了。

中间那盏，还亮着一点。

「表上零伏。」序说。

「记上。」

「那盏——」

「记上。」

衡先剪塔里那个，再剪序那个。两个饼落进铅匣。

「写收条。」

「封完写。」序说。

序掀开井盖。一股焦味上来，不重。

手电照下去。井壁黑了三尺，黑到接头上面。接头是新的：铜亮，热缩管紧，锡灌得满。表笔搭上去，零点零二。手背贴近，井里十八，接头二十二，四度。

衡蹲在井边，往下看。

「七年前，谁封的井？」

「册上写，准校验。」

「准校验不在册上了。」

「牌在。牌在，人不在。」

「人在。」序说。

男孩蹲在井底，仰头看那一圈黑。

「三层。」他说。

「三层。」序说。

钟楼那边响了。

一，二，三，四，五，六。

序把麻线从男孩手里接过来。结还在。七十九厘米半。他把麻线搭在井沿上，结卡进砖缝，铜螺母垂进井口。男孩蹲在井边，手伸进井口，悬在螺母回来的地方。

「我放，你数。」

「看不见。」

「不用看。它碰你的手。」

螺母荡出去，回来，碰在男孩手心里。

「一。」

二。三。四。五。六。

第七下。

钟声响。螺母荡出去。男孩的手在底下等着。

螺母过去，没有回来。

钟声停了。

「半个。」男孩说。

黑着，有人跟着说：「半个。」

衡站在井边，没有出声。

「七年前，也是半个？」序问。

「七年前，我没在这儿。」

「你在哪儿？」

「在册上。」

钟声散了。街上还黑着。赫菲的声音从人堆里出来。

「六个来回。第七个，半路。两回我都看见了。」

序合上井盖。

衡打开封钳箱，取出一一四那格字模，嵌进方槽。穿铅丝，剪断，两端塞进封耳，合上钳口。铅被压扁的声音很轻。饼上是一一四。表箱也补了封，一一三。

序合上总闸。街上的灯一盏一盏亮起来。

她翻开册子，在最后一页写：霜降后第十四日。表。补封。一一三。井。补封。一一四。压封：衡。

册背的封签旧了，边角起毛，上面一行字还看得清：第七校验·未至。

「第七校验，是什么？」序问。

「册上没写。」零说，「只写了日子。第六百七十三年·霜降。」

「那今年呢？」

「今年的日子，空着。」

写完，她画了六道横线，又划一道斜线。

「六行。」序说。

「补封，前六日无记。」

「无记，是没记，还是没发生？」

「册上不分。」

「人分。」

赫菲在人堆里说：「六行空，比六行字重。」

「重多少？」男孩问。

「重一个人。」

衡写收条：井上铅封二枚。临时封一，副封一。副封号：一一四。按印，递给序。

「副封，册上有吗？」

「收条上有。」

序走到街口，揭起一张火单。起火原因那一栏，空了七年。

「填上。填你看见的。」

女人接过铅笔，写：井内接头，布包线，碳化。年轻的复核员走过来。

「毁单。」

「填了，就在纸上。」衡说。

女人把单子举起来给街上的人看。

「丁九的册呢？」序问。

「在候册。候册不换，等正册有空。」

「钟册在哪儿？」

「回响塔。三天。」

「霜降那页，也有空行？」

衡看了他一眼。

「有。几行，你自己去数。」

车走了。街灯亮着。

夜里，井边没有人。序坐在井沿上，新封的铅还是软的。脚步声从街口过来，很慢，鞋底是软的。

那人在井沿另一头坐下。

「牌。」他说。

序把牌摸出来。牌边一一五。他递过去。那人接过去，翻了一下，没有看号，塞进袖子里。

「你的呢？」

序把自己的牌也递过去。牌面空的，边上磨得发亮。

「没有号。」

「没有号，也算封过。」他把牌递回来。

「那一页上，写的是你。」

那人不答。

「七年·霜降，第七响，短多少？」

「那天我在井里。听不见，数的是回声。」

「几下？」

「七下。第七下，短。」

「短多少？」

「你量的是多少？」

「零点九。」

「对。」

「封钟的人，不在井里。」

「在哪儿？」

「回响塔。钟册上，空行比字多。」

那人从袖子里摸出一样东西，放在井沿上。

一把封钳。铜的，巴掌长，钳口里有一个方槽。

「井上用不着了。」

「你用不着，我也用不着。」

「你会用着。」那人说，「开那些不让你看的。」

序凑近灯。方槽里嵌着一片字模，三个数：一一四。

「模子是你的。井上那个封，是你压的？」

「不是。」

「模子是你的，封不是你压的？」

「号好刻。」那人说，「缺口难刻。」

零的眼睛亮了一下。0x00。

「我见过这把钳子。」它说。

「在哪儿？」

「记录里没有地方。只有声音。铅被压扁的声音。」

那人看了零一眼，伸手在它壳上碰了一下。

「你还记得。」

「记得一段。不记得前后。」

「够了。记得铅，就够了。」

那人把手放在井盖上，隔着一层铁，摸了摸接头的位置。

「凉的。」

他站起来。

「你去哪儿？」

「牌取了。」

「还回来吗？」

「人在册上。」他说，「册上没我。」

他走了。帽檐压得很低。序没看见他的脸。街灯把他的影子拉长，压在井盖上。

序就着灯看拓片。拓片上那个「四」，角是齐的；钳子里的模子，右上角缺了一块。

「两个模子。」零说，「一个号。塔里那个不缺，齐的。」

「齐的，是假的。」序说。

序把封钳拿起来。比他想的沉。

「拿不拿？」

「我定了，这钳子就是我的。明天说不清。」零说，「先拓。再写。再找两个人。」

序拓了。这一回，他拓得很慢。拓完，他写：

拾得：封钳一把。地点：丁九·十七号井，井耳。时辰：亥时。在场：——

他推醒老头和男孩。

「半夜叫我，就为看一把钳子？」

「为看我从哪儿拿的。」

序把封钳放在井耳上，拓片放在旁边。老头按了一个手印。男孩也按了一个。

「两个手印。」零说，「也算两个人。」

「十两零四分。」它又说，「没称过。我记得。」

序看着它。零的眼睛暗着，0x00。

「记得，就是有过。」

「有过，不一定在纸上。」

「两栏，要占两格。格是死的。」零说，「记一栏，删一栏；记两栏，删两栏。」

「占。」

「删什么？」

零没有立刻答。它胸前的灯闪了一下。

「工坊那盏灯。」它说，「你修好它的那天。几月几号，你怎么接的线，它亮的时候你说了什么。」

「那也算一格？」

「算。」

「删了会怎么样？」

「我会记得有一盏灯。不记得是哪天亮的。」

序看着它。街灯的光落在它壳上，一道一道。

「还有？」

「还有你爹留下的那把钳子，第一次压封压偏的那一回。」零说，「删哪一栏，我定不了。」

「我定。」

「你定，也是删。」

序沉默了很久。风从井口上来，带着一股焦味。

「记。」他说，「删灯的那天。」

零的眼睛暗了一下，又亮起来。0x00。

「记了。」它说，「两栏。」

「你记得什么？」

「记得你说过，灯亮了，就算修好了。」

「这是哪天？」

「不记得。」

序没有再问。他把手按在井盖上，井盖是凉的。

「塔的写法：初八复封，册上无记。十四补封，六行空。合册。」

「我的写法？」

「井上两个封。一个六天，一个七年。册上只记一个。」

序把拓片和收条夹在一起。六行空格，他抄在第二页，一行一行，抄得很齐。

他抬头。回响塔在天边，塔尖上没有灯。

他把封钳放进袋里。袋里还有一张收条，一个号，六行空的抄本。

铜贴着纸。

街灯闪着：三短，三长，三短。他没有去数。
