# CH07 简报：第七章（暂名）《闭塔的一年》

> 版本：V1（2026-11-09，待 R3 严审 ch07 接口回来后修订）。
> 依据：ch06 结尾「册上没我。可有人叫得出我。」+ ch06 交接（塔闭一年、六页被抽的初八到十三、钟册压痕下的字、序无号、迟的「三天」、小满已开口）。

## 1. 本章任务

1. 让「序无号」成为具体障碍：进塔、查册、领工单、被街坊认出——四道门，三道关。
2. 把「六页被抽」从谜面变成线索：被抽的是初八到十三，不是随便六天；这六天里塔里发生了什么（与序被抹的记忆同一条线）。
3. 回收「迟的第三天」：第三层封被谁先封？——引出「两个模子」的第二个使用者（不是塔，也不是迟）。
4. 让零付第二次代价：上一章删了两格，这一章它开始「记错」——报错一个数，导致序判断失误（活人代价）。
5. 小满线推进：她叫得出序的名字，是因为她也在「册外」；她开始把序的名字写在自己的纸上——「自造册」的第一笔。
6. 章末钩子：换一种（不再用灯/钟）：塔闭一年后，第一张「无名工单」出现在序的工坊门口，工单上只有一行字：「第七校验，提前。」

## 2. 七场结构（每场 500–900 字）

1. **闭塔第一日**：街灯还亮，塔门封条；没有塔的读数，街上的表开始「走不准」；序第一次意识到：塔不在了，时间反而乱了。
2. **候册层侧门**：铜角按册放行——序无号，进不去；衡从侧门带他进；条件是「你替我签一张单」（衡动机延续）。
3. **六页的日期**：候册层第六架，初八到十三的六页被抽，留下的压痕是「换封」的笔画；序拓压痕，拓出半个「衡」字。
4. **第三层封**：迟的第三天到期，第三层封却被人先封了；封钳痕迹：塔印齐、序模缺——两个模子之外的第三个；迟不在场，只留一根麻绳。
5. **零记错**：零报错一个读数（把 0.19 报成 0.91），序据此误判，导致一次现场失败（谁受伤/谁被记名）；零承认「那一格，被删过」。
6. **小满的纸**：小满把自己的名字和序的名字写在同一张纸上，问「这样算不算上册」；序教她写「校验」两个字——第一次「教」，不是被教。
7. **无名工单**：夜里，工坊门口出现一张没有落款的工单；最后一行：「第七校验，提前。」；序抬头，塔闭着，街灯一盏没亮——但他手里的钳表，跳了一下。

## 3. 五条接口（ch06 交接）

- 塔闭一年：不是封印，是「塔里的人也在等」——闭塔是为了不让外面查册。
- 六页被抽：初八到十三≈封被换的六天；抽页的人不想让「换封记录」留下来。
- 钟册压痕：压在「未至」下面的字，是「已至」还是「未至」被改过，留到卷三。
- 序无号：这一章的四道门，只开两道；剩下的用「衡的签名」和「小满的纸」绕过。
- 迟的「三天」：迟到场不如不到场——他留下的第三个模子痕迹，是给序的下一道题。

## 4. 正典与规则

- 封号不复用：一一三/一一四/一一五已用；本章新封号从一一六起（若出现）。
- 「准」只作旧职称；迟不正面出场（可留物证）。
- 测量段≤25%；四种钩子轮换，本章用「悬念钩」。
- 零的限制不变：只报数、不解释、不替序决定；被动记忆是可丢的。
- 语言红线同前：禁网文套词/口语缩略/形容词堆砌；每章 1–2 处静场、3 句可抄。
