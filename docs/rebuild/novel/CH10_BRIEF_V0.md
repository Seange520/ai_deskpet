# CH10 简报：第十章《三日》（V0，待 R9 报告校准）

> 依据：ch09 备注 ch10 交接两条 + ch09 正文。R9 报告出来后按 §7 接口修订为 V1。

## 1. 本章任务

1. **三日倒计时**：二十七日对单，三十日到期；塔来人接衡回页主位（补页人手印、页主栏）。开篇即倒计时，不拖过第三日。
2. **归位后衡认不认得序**：本场最大悬念。册上写谁就是谁——归位后衡是「衡」，还是「不记得自己叫什么的那个她」？她若认得序，认的是名字还是人？
3. **第三把钥匙/空木匣**：册记「遗失」，实在旧棉袍无号者手里；让钥匙或空木匣在赫菲炉边/工坊再出现一次，把「十七日一炷香、出来手是空的」推一格。
4. **序的「一栏」**：ch09 补页人栏被划；ch10 序会不会为了留住衡，主动要求上册（有号）？代价是什么（A13/A14）。
5. **零的格数**：ch09 已为序付出「忘记三下约定」；ch10 若归位需再动一次记录，零还剩几格？让格数变成可数的倒计时。

## 2. 七场结构（每场 500–900 字）

1. **倒计时第一日**：塔里传话到街口，三日之内页主归位；序找衡，衡在页主栏按过手印，正把自己抄的一份补页单折进衣袋。
2. **空匣**：赫菲炉边出现空木匣（盛封钳的匣），匣底有旧棉袍纤维；序追到工坊，无号者只留一炷香与炉灰上的脚印。
3. **账不是册（对单）**：塔来人当众对单：页主衡、补页人序、见证空；序要求「见证」一栏写自己名字，被拒；铜角只记录「有异议」。
4. **第二日夜里（真静场）**：序与衡隔井而坐，写物：灯、绳、水、手印、纸；衡背得出补页单的每一行，却背不出自己的名字；序教她念「衡」。
5. **归位日**：塔来人接衡；序到场；册上写谁就是谁——衡归位瞬间的反应（认得/不认得），全场静；序按下自己的手印（若他选择上册）。
6. **代价**：序若上册，零必须删格（两栏制反噬）；序忘记的必须是一个具体的人（例如小满）或一件具体约定；写成可以传下去的物（折纸/门缝/灯）。
7. **章末钩子（选择钩/悬念钩）**：衡归位后夜里来找序，说一句只有页主才知道的话；或序手里多了半张补页单——页面写着自己名字，但「见证」栏空着，等着谁按手印。

## 3. 正典与规则

- 时间：第二十七日对单、第三十日到期；三日倒计时；§1–§2 不写日期另起。
- 封号体系：一一七仍为主物证；塔认页主，不认补页人（ch09 已立）。
- 衡：A14 代价已兑（不记得名字）；归位后是否恢复记忆，由本章决定，但一旦恢复，代价需转嫁（A14 守恒）。
- 迟：不正面出场；空木匣/钥匙作物证。
- 零：只报数、不解释；两栏制删格代价落到序。
- 测量段窄口径 ≤25%、单段工程动作 ≤3 句（A20）；本章工程动作=对单/按手印/开空匣，压缩至必要。
- 真静场至少 1 处（场四）；四种章末钩子轮换，本章用「选择钩」。
