## 正典默认（临时拍板，等主策划确认后转正式）

- 赫菲：男性，守炉人工坊主。
- 主角：第三人称「序」，见习校验员，铜牌编号空白。
- 七柱：小说只侧面写「灯柱/回路层旧制式」「七道槽」，不定「七座城」或「七个剖面」。
- 反派：只写「塔」「塔里的人」「复核员」，未定名。
- 术语：暂不使用「晶脉」「反峰」；「流明域」「七柱」「会呼吸的城市」「共振」「读数」为常驻词。
- 衡、准、秤：单字名；准的牌边封号一一五、井封一一四。
- 制度：七样封（表/井/牌/钟/印/册/封钳）一年一换，立冬换册；换册制「册上有名才算有人」；塔的精表 vs 街上的纸表。
- 钟与牌同构：七槽五凸两平（平槽灌铅）；塔钟七孔上二孔灌铅。
- 新增（待确认）：灯闪九秒一暗＝第三种「表」（不入塔表）；「复封」行政动作；量响器具三件（麻线结 79.5cm、铜砣三两七、纸蝶+铁罐一寸二）。

## 写作规范

1. 每章 3,400–4,800 汉字正文；300 字内出现钩子；章末留悬念。
2. 第三人称限知；工程解题链必须可复现（观察→记录条件→测量→对照→结论）。
3. 教学感只从行动与道具漏出：不许课程编号、不许老师式说教。
4. 世界观从工单、校验牌、读数、对话漏出：不许百科式旁白。
5. 禁用 AI 套话：「在这个世界上」「仿佛一切都」「眼中闪过一丝」「不由得」。
6. 每章末尾必须有「编辑备注」：伏笔、下章钩子、新增角色、冲突点。
