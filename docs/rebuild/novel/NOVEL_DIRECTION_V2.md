# 小说方向 V2：小说本体优先，世界观再造

> 主策划 2026-11-09 指令（paraphrased）：冲突点由 DSH 按最优解处理；整篇小说世界观要**新颖出众、跳脱常理又在情理之中**，具备与《龙族》《无职转生》《Re:0》竞争的品质；每章完成后以**专业小说评鉴师 + 资深读者**双视角严审，匠心打磨；**不为融入游戏元素而刻意迎合游戏设定与教学元素**——游戏改编与教学融入是制作端工作，不能本末倒置。

## 一、总原则（红线）

1. **先是一部好小说，再是一个 IP。** 课节编号、教学任务、游戏机制一律不得进入叙事；工程细节只为人物与悬念服务。
2. **世界观 > 设定说明。** 设定通过事件、禁忌、代价、仪式、日常细节漏出；禁止百科式旁白与解释性对话。
3. **每章必须有「惊艳点」。** 一个读者会截图发群里的画面/设定/转折；没有就不算完成。
4. **每章必须过双视角审稿**（评鉴师 + 老读者），评分不到线就重写，不许「先放着」。
5. **冲突点由 DSH 拍板**；正典以 `CANON_LEDGER` 为唯一真源，改设定必须回写台账。

## 二、世界观再造方案（选定）

### 2.1 核心奇观：世界本身是一份「校验单」

流明域不是一块大陆，而是一份**正在被校验的世界**。七柱是七个「校验位」；城市是一座被反复校对的巨大机器。所有存在——人、屋、路、灯——都必须**在册**，才算存在。不在册的东西会「漂移」：位置偏移、记忆变淡、被路人忘记，最后消失。

- **第七校验**：传说中每七百年一次的总校验。校验通过，世界继续；不通过，世界「回滚」重写。
- **塔**：不是政府，而是「校验执行机构」；它不统治人，它**校对**人。塔的精表记录「应然」，街上的纸表记录「实然」；两者差额就是「误差」。误差积累到阈值，区域就会被「修正」——人还在，但被改写成「一直如此」。
- **被校验者的恐怖**：不是被杀，而是**被改成一个从未存在过的人**。这是全书最深的恐惧，比死亡更冷。
- **主角的异常**：序的铜牌编号是空白——他是**未注册者**：世界不知道该怎么校对他是谁。他能看见「未入册的东西」：不该亮的灯、不存在的第七响、被删掉的记录。塔找不到他，因为他不在册；他也因此无法被世界保护——受的伤不会被「修正」，会真的死。

### 2.2 为什么这个设定新颖

- 把「校验/容错/冗余」这套工程师直觉，提升为**形而上的世界法则**：不是魔法体系，是**存在论**。读者能感到「合理」，因为现实里我们确实被记录、被打分、被归档。
- 与《龙族》的「血统与孤独」、《Re:0》的「回滚与代价」、《无职》的「重生与成长」形成对话：本作的核心是**「谁有权力定义你是谁」**。
- 悬念天生：读数为甚么被改？第七校验还有多久？塔在瞒什么？空白牌是诅咒还是钥匙？

### 2.3 力量体系（去数值化）

- 不写等级、不写面板。能力只有三种来源：
  1. **读数**：能看见别人看不见的量（序的天赋，来自空白牌）。
  2. **校具**：量响器、旧尺、铜印等「物」——每一件都有历史与代价。
  3. **入册**：被世界承认的人能借用「校订权」（登记、复位、封存），但每一次使用都在消耗**自己的册页**。
- 代价必须具体：用一次校订权，会忘掉一段自己的记忆；忘得越多，越容易被世界「改写成别人」。

### 2.4 情感内核

序寻找的不是真相，是**「我凭什么算数」**。零寻找的是**「我被删掉的那一段是什么」**。赫菲守着的不是炉子，是「最后一个还没被校对的人」。准留下的是「第十四天」，衡守着的是「程序」，秤守着的是「废铜里的名字」。每个角色都在回答同一个问题：**被记录，等于存在吗？**

## 三、与游戏的关系（明确分工）

- 小说按小说写：人物、悬念、情感、世界奇观优先。
- 游戏改编端负责：把小说里的「校验」翻译成可玩的测量/诊断/修复任务；教学融入由游戏设计完成。
- 小说里允许出现「无法被玩家操作」的宏大场面；游戏里允许出现「小说没写」的教学课节。**互不迁就，各自做到最好。**

## 四、审稿流程（每章强制）

1. **写**：4,000–5,000 字正文 + 编辑备注。
2. **冷读**：隔一轮再读，列出「无聊段落 / 解释腔 / 巧合 / 人物失真」。
3. **双视角评审**：
   - 评鉴师：世界观原创性、结构、主题深度、语言、节奏。
   - 资深读者：爽点/悬念/情感冲击/是否想追更/是否截图分享。
4. **评分表**（每项 10 分，均分 ≥8.5 才通过；任一项 <7 必须重写该段落）：

| 维度 | 评鉴师看什么 | 老读者看什么 |
| --- | --- | --- |
| 世界观惊艳度 | 是否自洽、是否前所未见 | 是否想住进去/是否害怕 |
| 开篇钩子 | 300 字内冲突 | 是否想翻下一章 |
| 人物 | 欲望/缺陷/变化 | 是否喜欢/心疼/好奇 |
| 情节 | 因果链、反转合理性 | 是否憋尿看完 |
| 文笔 | 节奏、意象、克制 | 是否好读、是否有金句 |
| 情感 | 主题落点 | 是否破防 |
| 追更欲 | 伏笔与结构 | 是否想立刻看下一章 |

5. **不改完不交**。完成后更新 `novel/README.md` 与伏笔台账。

## 七、文学性与史诗感（主策划追加指令）

> 辞藻编辑要突出**文学性、史诗性**，别太土；游戏以小说为蓝本，不是小说迎合游戏。

### 7.1 禁止的「土味」写法

1. **操作说明书腔**：连续罗列「调到某档—读数—点头—再调」的流程句。工程动作可以写，但必须挂在人物的情绪/代价/悬念上，且每段不超过三句。
2. **网文套词**：心中一惊、瞳孔一缩、一股寒意、倒吸一口凉气、不由得、仿佛一切都、在这个世界上、说白了、总之。
3. **现代口语缩略**：「搞定」「没辙」「贼快」「整」「呗」——除底层配角一句半句，叙述层不用。
4. **形容词堆砌**：「宏伟壮观」「令人震撼」「无比强大」——宏大要用具体物象与代价写，不靠形容词。
5. **解释性内心独白**：把世界观掰开揉碎讲给读者听。设定只允许从动作、禁忌、仪式、代价里漏。

### 7.2 要的写法（史诗感的来源）

- **以物写神**：一只灯闪九秒，写的是整座城的时间被谁攥着；一枚铜印两槽灌铅，写的是七柱被抹成五域。
- **以日常写神话**：换封、上册、报关、复封—— bureaucracy 写成仪式，读者才会发凉。
- **以代价写规则**：每次动用校订权忘掉一段记忆；读者从人物的遗忘里理解世界法则，而不是从旁白。
- **静场**：每章 1–2 处「所有人都停下」的静场，只写声音、光、动作，不写心理。
- **长短句**：叙述用中长句铺陈，关键判断用四到七字短句砸下去。「合册的不算错。」「纸没了，账就平不了。」
- **意象复用**：灯、线、册、印、铅、灰、铜、霜降、雨——每个意象反复出现并承载新含义，形成本书的「神话语法」。
- **克制的抒情**：情感最重处反而收着写，留白给读者。禁止「他感到无比悲伤」这类直给。

### 7.3 每章自检（并入双视角审稿）

- 是否有至少 3 处「可以抄在本子上」的句子？
- 是否有一处让读者停下呼吸的静场？
- 是否有一处「把宏大写成具体」的画面？
- 删掉所有解释后，读者还能看懂世界在发生什么吗？

### 7.4 对 ch01–04 的含义

前四章的工程推理骨架保留，但语言层要做一次**文学化重写**：
- 压缩连续测量流程，把「测」写成**人物在黑暗里摸索的紧张**；
- 加入静场与意象（灯、册、霜）；
- 把「教学感」的句子改写成人物口吻的短句或干脆删除；
- 史诗感从 ch02 起逐步抬升：衡的塔、钟册、七槽铜印，都要写成「神话里的官僚，官僚里的神话」。
