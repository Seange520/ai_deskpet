# 刀子设计 V1（情感冲击设计）

> 09:00 主策划方向：剧本里要有「能调动情绪的刀子」；作为作品引人的组成，允许学习更多技巧。
> 本文件=《第七校验·流明域》小说/游戏共用的刀子设计手册与台账，写章节与审稿时逐章对照。

## 1. 原则（先立规矩，再下刀）

1. **刀必须从暖里长出来**：先给具体的好（一碗面、一只折纸、一句口头约定），再拿走。没有暖的刀=虐，读者不买单。
2. **刀不见血**：越疼越克制。写物、写动作、写停顿，不写「他心如刀割」。
3. **一刀一物**：每一刀必须留下一个可传下去的物件（折纸、刻痕、空匣、手印、浆糊印），后文可回访。
4. **延迟比即时狠**：让读者先知道，角色后知道（序忘记约定，读者记得；小满记得，序不记得）。
5. **刀要还**：刀子不是一次性；被拿走的东西要在后文以另一种形式「还一半」（找回名字但忘了脸、找回脸但人已不在）。
6. **不连刀**：连续两章不用同一类刀；大刀子至少隔三章。
7. **配角刀比主角刀更稳**：主角尚未让读者爱，先刀配角（陈四、卖炭人、老太太、衡）。
8. **每卷 1 把主刀、2–3 把小刀**：主刀放在卷末前两章（选择刀/身份刀），小刀散在 1/3 与 2/3 处。

## 3. 现有存量（ch01–ch09 已埋的刀）

- ch01：老太太空屋两只碗（K2/K8）；卖炭人「我闺女今年六岁」→「咱没有闺女」（K4/K8，已埋未收，ch05 接了小满）。
- ch03：十一家联名按手印、秤砣被没收（K2/K6）。
- ch04：陈四档号被当众念（K6）。
- ch05：小满折纸「纸在，她就在」（K1/K2，强埋）；迟「牌取了」「册上没我」（K5）。
- ch06：出塔被忘名（K3）；小满叫出「序」（K1 回甜）。
- ch07：补页上「页主衡」三个字（K3/K7）。
- ch08：衡刮名、认得字叫不出（K3/K7）。
- ch09：删「三下」、序忘「灯亮三下就回来」（K4/K11，已下刀未爆）。

## 4. 待下刀位（ch10–ch15，与《三日》《第十四天》等衔接）

- ch10 归位日（K9/K10）：衡回页主位，册上写谁就是谁——序是否上册换她留下；若上册，零删格，代价落到序忘小满。
- ch11 两难之后（K1/K6）：小满再折一只纸，写「第四个名字」；序不记得门缝。
- ch12 迟的真相（K5/K7）：迟为什么在册外；他把牌还回来的那半块。
- ch13 全城（K8）：塔用「补页」一次性抹掉某条街；序只能救一个人。
- ch14 选择（K10/K3）：序有号之后，第一个被要求签的字是抹掉迟。
- ch15 卷末主刀（K1+K4）：序终于记起一个名字，但那名字已不在册上——「记得的人，比被记得的人更疼」。

## 5. 每章自检（写作者/审稿人勾选）

- [ ] 本章至少 1 刀（或为下一刀埋暖/埋物）？
- [ ] 刀前 3 章内有对应的暖场？
- [ ] 刀后留了可回访的物？
- [ ] 没有直接写「心痛/泪如雨下」？
- [ ] 与上一章的刀不是同一类型？
- [ ] 刀是否推动主线（而非纯虐）？
- [ ] 主角/读者信息差用上了吗（延迟刀）？
