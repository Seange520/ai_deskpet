# Codex 任务卡 01：三渲二渲染原型（R1）

**目标**：在现有 Three.js/R3F 工程里做出「明亮幻想·卡通渲染」单场景原型，证明视觉方向可行。

**范围（只动渲染层，不动教学逻辑）**
- 新增/改造着色器：Toon 色阶（3–4 阶）、边缘描边（后处理或法线外扩）、高光/皮肤/布料简化。
- 天空与氛围：渐变天空 + 程序化云 + 远景极光保留；雾/丁达尔光；昼夜时间旋钮。
- 后处理：Bloom、DOF（可选）、Color Grading（LUT）、Vignette、轻微颗粒。
- 单场景：一条街 + 2 个角色/桌宠 + 地标塔，作为对比截图场景。

**验收**
1. `?quality=3&render=toon` 可切换对比（默认关闭）。
2. 4 张 1080p 截图：白天/黄昏/夜晚/描边开关对比，存 `work/acceptance/render-r1/`。
3. 性能表：该场景中端桌面 1080p 平均帧 ≥55；Draw Call 与三角面统计。
4. 控制台 0 error；`npm run build` 通过；E2E 67 不破。
5. 不引入 GPL/不可商用素材；新增依赖需在 PR 说明许可。

**交付**：分支 `feat/render-toon`；提交说明含截图与性能数据；不推送 main。
