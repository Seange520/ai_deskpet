# Codex 任务卡 02：原神式 UI 信息架构骨架（R2）

**目标**：按 `PIVOT_GENSHIN_V1.md` 第 3 节，做出原创视觉的 HUD 与五大面板骨架（可空数据）。

**必须实现**
1. 主 HUD：顶部状态条（体力/等级/货币占位）、左上圆形小地图（可展开）、右侧任务追踪、底部快捷栏（仪表/工具/技能三栏）、交互提示、跳跃/冲刺键。
2. 五大面板骨架：角色（属性/天赋/装备）、背包（分类/筛选/详情）、地图（图层/图钉/传送）、任务（主线/支线/日常）、教学（校验之径）。统一「左标签 + 右内容」全屏面板与返回路径。
3. 设计 token：颜色/字号/间距/圆角/动效时长，写入 `src/ui/tokens.css`；深色玻璃与浅色纸张两套变量（跟随现有 theme 系统）。
4. 响应式：桌面 16:9 与手机 19.5:9 横屏；触控热区 ≥44px。
5. 键位：C/B/M/J/L/Esc 打开对应面板，手柄预留映射。

**验收**
- 截图 6 张（HUD + 五面板，1920×1080 与 390×844 各一组关键屏）。
- 无控制台错误；面板切换 240ms 动效；`npm run build` 通过；E2E 67 不破。
- 不照搬原神图标/贴图/字体；图标用开源集（Lucide/自绘）。

**交付**：分支 `feat/ui-frame`；提交说明 + 截图目录。
