# Codex 任务卡 03：去掉「进入按钮」的启动流（R2）

**目标**：桌面与手机 App 启动后不再出现「开始自由探索/进入世界」按钮，直接进入可操作世界；保留失败兜底与设置入口。

**流程要求**
1. 启动 → 校验协议加载页（进度/提示文案）→ 短过场（可跳过）→ 直接落地出生点，HUD 淡入。
2. 首次运行：创建角色/命名（可跳过，默认名）；之后不再询问。
3. 加载失败：显示重试/离线模式（教学离线可用）。
4. 设置入口保留（画质/主题/音效/重置）。
5. Web 官网预览页可保留按钮（与 App 区分），但 App 内无按钮。

**验收**
- 录屏 20s：双击 exe / 手机启动 → 可直接 WASD 移动，无按钮点击步骤。
- 冷启动到可操作 <15s（中端桌面）；DevTools console 0 error。
- 断网启动可进入离线世界（教学可用）。
- E2E 67 不破；新增启动流不得破坏现有 boot 测试（如有需更新断言并说明）。

**交付**：分支 `feat/boot-direct`；录屏 + 截图。
