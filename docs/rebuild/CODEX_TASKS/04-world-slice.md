# Codex 任务卡 04：大世界可玩切片（R3）

**目标**：1 主城 + 1 野外 + 1 秘境的可玩灰盒切片，验证「探索→解谜→材料→制作→剧情」循环。

**范围**
- 主城（熔炉城）：3 个 NPC、1 个工坊（工作台）、1 个传送塔。
- 野外（晶脉荒原）：1 个解谜点（电路谜题）、2 个采集点、1 个宝箱、1 个地标（视线引导）。
- 秘境：1 个教学副本（七段任务的一节，复用现有 LessonRunnerV2）。
- 系统：传送、采集、背包（材料计数）、任务追踪、体力/攀爬滑翔（灰盒即可）。
- 地图：流式分块灰盒（1km×1km 内 4 块），LOD 占位。

**验收**
- 一段 5 分钟实机录像：探索 → 解谜 → 获得材料 → 提交任务 → 进入秘境课节。
- 帧率：中端桌面 1080p ≥55；手机 720p ≥28（或说明未达项）。
- 0 console error；build ✓；E2E 67 不破。
- 素材原创/CC0；不复制原神场景与任务文本。

**交付**：分支 `feat/world-slice`；录屏 + 性能数据 + 已知问题清单。
