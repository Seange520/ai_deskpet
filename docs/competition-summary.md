# SparkMate · 竞赛 / 大创答辩一页纸摘要

> **一句话**：把 ESP32-S3 硬件教学装进浏览器，让零基础学生通过「四条桌宠路线」在 30 分钟内完成从物料认知到代码调参的完整闭环。

## 2. 痛点（Why）

- **硬件门槛高**：新生要先买板子、装工具链、查引脚，第一步就卡住，兴趣在「点灯」前耗尽。
- **试错代价大**：电源接反、舵机供电不足可能直接烧毁器件，课堂难以让每个人都动手。
- **反馈周期长**：改一行代码要编译、上传、看现象，学习正反馈慢。
- **课程同质化**：多数教学停留在「点亮 LED」，缺少能让非科班学生「拿得出手」的作品。

## 3. 方案（What & How）

**四条创作路线 × 三关学习路径 × 一套状态与奖励系统**

1. **选路线**：经典方块桌宠 / 迷你四足机器狗 / 履带·麦轮小车 / 球形自平衡机器人。
2. **学三关**：认识物料（+100 XP）→ 虚拟接线（+250 XP）→ 代码调参（+150 XP）。
3. **看反馈**：爆炸图拆解、拖拽接线、错误分级、模拟烧板、桌宠表情、合成音效、成就徽章。
4. **留成果**：本机保存进度、生成体验证书与分享卡，形成可展示的学习证据。

```text
选路线 → 认物料 → 接线 → 代码调参 → 领成就 → 换路线/进阶
   └────────── Zustand 全局状态贯穿全程 ──────────┘
```

| #   | 创新点                  | 说明                                                                            |

| 1   | **多形态桌宠叙事**      | 把硬件形态（方块 / 四足 / 小车 / 球形）包装成四种「伙伴」，学习目标即「唤醒它」 |

| 4   | **可测试的教学交互**    | 爆炸图与接线用计算样式指纹断言，注入缺陷可稳定捕获，演示与质量可复现            |
| 5   | **成就 + 音效情感闭环** | 徽章、Toast、桌宠表情与 Web Audio 合成音效协同，刷新不重播、重置不误发          |

## 5. 成果与验证（Proof）

- **产品**：四条路线完整可玩，部署于 Vercel，公网可访问、无需后端。
- **质量**：`npm run build` 通过；44 项 Playwright E2E 全绿；`npm run qa` 上线前质检 5 PASS / 1 WARN / 0 FAIL。
- **教学性**：每条路线含分路线避坑笔记与「危险操作」后果演示，强调安全规范（独立供电、共地、断电操作）。
- **可维护性**：配置与视图分离，测试覆盖路线、状态迁移与降级路径。

## 6. 应用场景与用户

- **高校新生导览 / 金工实习先导课**：课堂投屏演示 + 学生手机实操。
- **社团招新与开放日**：3 分钟体验即产出「我的桌宠」。
- **个人自学**：无硬件条件下先建立正确概念，再决定是否购入套件。
